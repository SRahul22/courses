    The maths toolkit behind GATE DA

    GATE DA leans on a compact set of maths tools. This module recaps them in one place: functions and logs, sums and sets, derivatives and integrals, vectors and matrices. Each chapter shows where the idea turns up in real GATE questions, so you know why you’re learning it.

    New to this, or has it been years? Start at Chapter 1.1, which reads the symbols aloud, and take the warm-up problems at the top of each practice set before the harder ones. Words with a dotted underline can be tapped for a plain definition. Already comfortable with a chapter? Jump straight to its quiz: if you get it right, move on. Every later module builds on these ideas.

    The route

      Start here if maths has been a while. The first chapter is a phrasebook for the symbols every later page uses: kinds of numbers, intervals, subscripts and Greek letters. Then come the two ideas every other module quietly depends on. First, functions and their graphs: lines, parabolas, absolute values and the piecewise functions that GATE uses to describe probabilities. Second, exponentials and logarithms, which run through the exponential distribution, the sigmoid in machine learning and entropy in decision trees.

      You need: arithmetic and the idea that a letter can stand for a number. That’s it.

      Reading maths: numbers, symbols and notation

      Maths is written in a compact shorthand, and once you can read each symbol aloud in plain words, a question that looked frightening becomes an ordinary sentence.

      Every later chapter uses things like $\R$, $[1, 3]$, $x_1$, $\lambda$ and $5!$ without stopping to explain them. This chapter is the phrasebook: twenty minutes here saves a lot of confusion later.

      It’s like learning to read a bowling figure: “4–0–28–2” looks cryptic until someone tells you it means overs, maidens, runs and wickets. After that you read it at a glance.

      Why bother? Read one real sentence

      Here is how a 2024 exam question begins: "Let $X$ be a random variable uniformly distributed in the interval $[1, 3]$." Read slowly, it is only three ideas:

      • "$X$“ is a name for a number we don’t know yet, like ”the score in tomorrow’s match".
      • “uniformly distributed” means every value is equally likely (you’ll meet this properly in Probability).
      • "$[1, 3]$“ means ”any number from 1 to 3, including 1 and 3 themselves".

      So the sentence says: $X$ is a number somewhere between 1 and 3, and no part of that range is favoured. That’s the whole skill of this chapter: turning symbols back into words.

      Kinds of numbers

      Four families of numbers come up again and again. Each one contains the one before it.

      • Natural numbers $\N$: the counting numbers $1, 2, 3, \ldots$ (some books include 0). “How many tickets?” is a natural number.
      • Integers $\Z$: whole numbers, negatives included: $\ldots, -2, -1, 0, 1, 2, \ldots$ A team’s net run difference is an integer.
      • Rational numbers $\Q$: fractions of integers, like $\tfrac34$, $-\tfrac52$ or $0.25 = \tfrac14$.
      • Real numbers $\R$: every point on the number line, including numbers like $\sqrt2 \approx 1.414$ and $\pi \approx 3.1416$ that are not fractions. Heights, times and probabilities are real numbers.

      When you read "$x \in \R$“, say ”$x$ is a real number". The symbol $\in$ means “is a member of” (it’s a stylised E for “element”), and $\notin$ means “is not a member of”: $-3 \in \Z$ but $-3 \notin \N$.

      An interval is an unbroken stretch of the number line. A square bracket means the end is included; a round bracket means it is left out.

      • $[a, b]$: $a \le x \le b$, both ends in.
      • $(a, b)$: $a \lt x \lt b$, both ends out.
      • $[a, b)$: $a \le x \lt b$, left end in, right end out.
      • $[a, \infty)$: $x \ge a$, no upper limit. Infinity always gets a round bracket, because no number reaches it.

      Subscripts, indices and Greek letters

      A small number written low, as in $x_1$, is a subscript. It’s part of the name, not arithmetic: $x_1$ is “x one”, the first of several values $x_1, x_2, x_3, \ldots$ If a batter’s scores in five matches are 30, 12, 55, 0 and 41, then $x_3 = 55$. Two subscripts, as in $a_{23}$, give a row and a column in a table (row 2, column 3).

      A small number written high, as in $x^2$, is a power (“x squared”, $x \cdot x$). You’ll revise powers in the next chapter but one.

      Factorials, fractions and percentages

      The factorial $n!$ multiplies every whole number from $n$ down to 1: $5! = 5\cdot4\cdot3\cdot2\cdot1 = 120$. It counts the ways to put $n$ things in order (five batters can be arranged in 120 batting orders). By agreement $0! = 1$. Factorials grow fast, so cancel before multiplying: $\dfrac{6!}{4!} = \dfrac{6\cdot5\cdot\cancel{4!}}{\cancel{4!}} = 30$.

      Probabilities are written three ways, and you should switch between them without thinking: $\tfrac14 = 0.25 = 25\%$. To turn a fraction into a decimal, divide: $\tfrac38 = 3 \div 8 = 0.375$. To turn a decimal into a percentage, multiply by 100.

      Functions: machines that turn one number into another

      A function takes an input number and returns exactly one output number, and its graph is a picture of every input–output pair at once.

      Probability distributions, loss functions, activation functions, eigenvalue equations: almost everything in GATE DA is a function. Reading one quickly is a skill you’ll use in every module.

      It’s like a vending machine: press button B4 and you always get the same snack. Same input, same output, every time.

      Where it shows up in GATE DA

      Rarely asked on its own, but used everywhere. Piecewise functions describe distributions and activations; you’ll need to read them fluently.

      Suppose the Data Premier League charges ₹200 per ticket, plus a ₹50 booking fee per order. If you buy $x$ tickets, you pay $200x + 50$ rupees. That rule is a function. We give it a name, say $f$, and write

      $$f(x) = 200x + 50.$$

      Read $f(x)$ as “f of x”: the output when the input is $x$. So $f(3) = 200\cdot 3 + 50 = 650$. The letter $x$ is just a placeholder; $f(t) = 200t + 50$ is the same function.

      The graph of $f$ is the set of all points $(x, f(x))$ drawn on a grid. The horizontal axis holds inputs and the vertical axis holds outputs. A graph lets you see a function’s whole behaviour at once: where it rises, where it falls, where it crosses zero.

      A function $f$ assigns to each allowed input $x$ exactly one output $f(x)$. The set of allowed inputs is the domain. "$f:\R\to\R$“ reads ”f takes a real number to a real number": inputs are real numbers, outputs are real numbers.

      The five shapes you’ll meet constantly

      • Line $f(x) = mx + c$. The slope $m$ says how much the output rises per unit step right; $c$ is where it crosses the vertical axis. Through two points $(x_1, y_1)$ and $(x_2, y_2)$ the slope is “rise over run”, $m = \dfrac{y_2 - y_1}{x_2 - x_1}$. The ticket function passes through $(1, 250)$ and $(3, 650)$, so $m = \dfrac{650 - 250}{3 - 1} = 200$: each extra ticket adds ₹200.
      • Parabola $f(x) = ax^2 + bx + c$. A U shape if $a \gt 0$, an upside-down U if $a \lt 0$. Its turning point (the vertex) sits at $x = -\dfrac{b}{2a}$.
      • Absolute value $|x|$: “drop the minus sign”. $|{-3}| = 3$, $|3| = 3$. Its graph is a V. Geometrically, $|a - b|$ is the distance between $a$ and $b$ on the number line.
      • ReLU $\max(0, x)$: zero for negative inputs, the input itself otherwise. It’s the most common activation function in neural networks.
      • Piecewise functions use different rules on different stretches of the input. ReLU is one; so is the ticket function above if bulk orders get a discount.

      Solving equations and inequalities

      "Solve $f(x) = k$" means: which inputs give output $k$? On the graph, draw a horizontal line at height $k$ and read off where it hits the curve.

      • Linear: $200x + 50 = 1050$ ⇒ $200x = 1000$ ⇒ $x = 5$. Do the same thing to both sides until $x$ is alone.
      • Quadratic: $ax^2 + bx + c = 0$ has solutions $x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$. The part under the root, $b^2 - 4ac$, is the discriminant: positive means two real roots, zero means one, negative means none (the parabola never touches the axis). You’ll meet this again with eigenvalues.
      • Inequalities work like equations, with one twist: multiplying or dividing both sides by a negative number flips the sign. $-2x \gt 6$ ⇒ $x \lt -3$.
      Careful: with fractions, cross-multiplying $\dfrac{p}{q} = \dfrac{r}{s}$ into $ps = qr$ is fine for equations. For inequalities it is only safe when you know the denominators are positive.
      GATE DA 2025 · Q19 · MCQ · 1 mark

      Let $X$ be a continuous random variable whose cumulative distribution function (CDF) $F_X(x)$, for some $t$, is given as follows:

      $$F_X(x) = \begin{cases} 0 & x \le t \\ \dfrac{x-t}{4-t} & t \le x \le 4 \\ 1 & x \ge 4 \end{cases}$$

      If the median of $X$ is 3, then what is the value of $t$?

      1. 2
      2. 1
      3. −1
      4. 0

      You don’t need to know what a CDF is yet (that’s Probability, Part 3). All you need: the median is the input where $F_X$ equals ½. Everything else is reading a piecewise function and solving an equation.

      1. The median is 3, so $F_X(3) = \tfrac12$.

        This is the one fact we’re given. It turns the question into an equation.

      2. Which piece applies at $x = 3$? The middle one, as long as $t \le 3 \le 4$. So $\dfrac{3-t}{4-t} = \dfrac12$.

        A piecewise function uses different formulas on different stretches. The outer pieces are flat at 0 and 1, and neither can equal ½, so it must be the middle piece.

      3. Cross-multiply: $2(3 - t) = 4 - t$ ⇒ $6 - 2t = 4 - t$ ⇒ $t = 2$.

        Safe for an equation. Collect the $t$ terms on one side: $6 - 4 = 2t - t$.

      4. Check: $t = 2 \le 3 \le 4$ ✓, and $F_X(3) = \tfrac{1}{2}$ ✓. Answer (A) 2.

        Always check that your answer is consistent with the assumption you made in step 2 (here, that 3 lies in the middle piece). On GATE, plugging your answer back in costs ten seconds and catches most slips. The official key agrees: (A).

      Go deeper: why the vertex is at −b/(2a)

      A function is defined in pieces: $f(x) = kx$ for $0 \le x \lt 2$, $f(x) = k(4 - x)$ for $2 \le x \le 4$, and $f(x) = 0$ everywhere else, where $k \gt 0$ is a constant. The total area between the graph of $f$ and the $x$-axis is 1. Find the area under the graph between $x = 0$ and $x = 3$.

      How many integers $x$ satisfy $x^2 - 5|x| + 4 \lt 0$?

      Let $f(x) = |x - 2| + |x + 1|$. Which of the following is/are true?

      1. The smallest value of $f$ is 3.
      2. The equation $f(x) = 5$ has exactly two solutions.
      3. $f$ reaches its smallest value at exactly one point.

      $|x - a|$ is the distance from $x$ to $a$, so $f(x)$ is the total distance from $x$ to 2 and to $-1$. Split the number line at $-1$ and $2$ and write $f$ without bars on each piece.

      • $x \lt -1$: $f(x) = (2 - x) + (-1 - x) = 1 - 2x$.
      • $-1 \le x \le 2$: $f(x) = (2 - x) + (x + 1) = 3$.

      Exponentials and logarithms: growth, decay and undoing them

      An exponential multiplies by the same factor at every step; a logarithm undoes that, answering “how many steps does it take?”

      The exponential distribution has appeared in every GATE DA paper so far, and you can’t touch it without $e^{-\lambda x}$ and $\ln$. The sigmoid in logistic regression and the entropy in decision trees are built from the same pieces.

      It’s like a rumour: each person tells two more, so the count doubles every round. The exponential tells you how many people know after 10 rounds; the logarithm tells you how many rounds until a million people know.

      Sums and series: adding up many things at once

      $\sum$ is shorthand for “add these up”, and a geometric series, where each term is a fixed fraction of the last, can add up to a finite number even with infinitely many terms.

      Two patterns you should know cold

      Arithmetic series (each term adds the same amount): $1 + 2 + \cdots + n = \dfrac{n(n+1)}{2}$. The trick: pair the first and last terms, $1 + n$, then the second and second-last, $2 + (n-1)$, and so on. Every pair sums to $n+1$, and there are $n/2$ pairs.

      Can you add up infinitely many numbers? Sometimes. Keep adding terms and watch the running total. If the totals settle down towards a fixed number, that number is the sum of the infinite series, and we say the series converges. If the totals keep growing (or keep jumping about), it has no sum. The geometric series is the one case you need to know well.

      Geometric series (each term multiplies by the same ratio $r$): $$a + ar + ar^2 + \cdots + ar^{n-1} = a\,\frac{1 - r^n}{1 - r}.$$ If $|r| \lt 1$, then $r^n \to 0$ as $n$ grows, and the infinite sum settles down to $$a + ar + ar^2 + \cdots = \frac{a}{1-r}.$$ If $|r| \ge 1$, the terms don’t shrink and the sum runs off to infinity (or never settles).

      Try it

      A sum inside a sum

      A double sum is a sum whose terms are themselves sums. Work from the inside out: fix the outer index, do the inner sum, then add up the results. For example $$\sum_{i=1}^{2}\sum_{j=1}^{3} i\,j:\quad i = 1 \text{ gives } 1 + 2 + 3 = 6;\quad i = 2 \text{ gives } 2 + 4 + 6 = 12;\quad \text{total } 18.$$ Because each term $i\,j$ is (something in $i$) × (something in $j$), there’s a shortcut: $(1 + 2)(1 + 2 + 3) = 3 \times 6 = 18$.       Sets: the language of “and”, “or” and “not”

      A set is a collection of distinct things, and union, intersection and complement are just “or”, “and” and “not” made precise.

      In probability, an event is a set of outcomes. In databases, relational algebra is set algebra. In Python, sets are a data type GATE writes code questions about. Learn this vocabulary once and you’ll use it in three modules.

      A set is written with curly braces: $A = \{1, 2, 3\}$. Order doesn’t matter and repeats don’t count, so $\{3, 1, 2, 2\}$ is the same set. We write $2 \in A$ (“2 is in A”) and $5 \notin A$. The empty set $\varnothing$ has nothing in it. $|A|$ is the number of elements, here 3.

      Sets also let you write sets of numbers by a rule: $\{x \in \R : x \ge 0\}$ reads "all real numbers $x$ such that $x \ge 0$". The colon (sometimes a bar, $|$) is read “such that”.

      Two counting facts

      • A set with $n$ elements has $2^n$ subsets (each element is either in or out: $n$ yes/no choices). Including the empty set and the set itself.
      • The Cartesian product $A \times B$ is the set of all pairs $(a, b)$, and $|A \times B| = |A|\cdot|B|$. Two dice give $6 \times 6 = 36$ outcomes. A database CROSS JOIN is exactly this.

      Derivatives: the slope at a single point

      The derivative $f'(x)$ is the slope of the curve at the point $x$: how fast the output changes when you nudge the input.

      Finding maxima and minima, training neural networks with backpropagation, and the sigmoid’s famous $\sigma(1-\sigma)$ all come down to derivatives. GATE asks one directly almost every year.

      It’s like the speedometer in a car. The odometer tells you distance (the function); the speedometer tells you how fast that distance is changing right now (the derivative).

      For a straight line the slope is easy: rise over run, the same everywhere. A curve’s steepness changes from point to point. To find the slope at one point $x$, pick a second point a tiny step $h$ away, draw the line through both (a secant), and measure its slope:

      $$\frac{f(x+h) - f(x)}{h}.$$

      Now shrink $h$ towards 0. The secant swings round and settles on the tangent line, the line that just touches the curve at $x$. Its slope is the derivative.

      Integrals: adding up area under a curve

      The integral $\int_a^b f(x)\,dx$ is the area under the curve of $f$ between $a$ and $b$, and you compute it by running a derivative backwards.

      For continuous random variables, probability is area under a curve. Every exponential, normal or uniform question in GATE hides an integral, and many of them can be done with plain geometry.

      It’s like filling a petrol tank: the pump’s flow rate changes over time, and the total fuel is the area under the flow-rate curve.

      Gradients: which way is downhill?

      For a function of several variables, each partial derivative measures the slope in one direction, and the gradient collects them into an arrow pointing uphill.

      Machine learning trains models by walking downhill on a loss surface (gradient descent). GATE has asked you to perform one step of it, and to compute gradients through a neural network.

      It’s like standing on a foggy hillside: you can’t see the valley, but you can feel which way the ground slopes under your feet, and you step that way.

      A function can take two inputs: $f(x, y) = x^2 + 3y^2$. In machine learning a model has many inputs to tune (its parameters), so this is the normal case, not an exotic one. Its graph is a surface, like a landscape. To draw it on paper we use a contour map: curves joining points of equal height, exactly like the contour lines on a hiking map.

      To measure slope, freeze all inputs but one. The partial derivative $\dfrac{\partial f}{\partial x}$ treats $y$ as a constant and differentiates in $x$ as usual. For $f = x^2 + 3y^2$: $\dfrac{\partial f}{\partial x} = 2x$ and $\dfrac{\partial f}{\partial y} = 6y$.

      $$\nabla f = \left(\frac{\partial f}{\partial x},\ \frac{\partial f}{\partial y}\right).$$ At each point, $\nabla f$ is an arrow pointing in the direction of steepest ascent, and it’s perpendicular to the contour line through that point. Its length is how steep it is. So $-\nabla f$ points steepest downhill.

      A pair like $(2x, 6y)$ is a vector: an ordered list of numbers that you can draw as an arrow, “so many steps across, so many steps up”. Part 4 covers vectors properly; here you only need to read the arrow. Vectors are printed in bold, so a point with several coordinates is written $\mathbf w$.

      Start at some point $\mathbf w$. Repeat: $$\mathbf w \leftarrow \mathbf w - \eta\,\nabla f(\mathbf w),$$ where $\eta \gt 0$ (eta) is the learning rate, the step size. Too small and progress is slow; too large and you overshoot the valley and may bounce out of it. Stochastic gradient descent (SGD) uses the gradient computed on one data point at a time.

      Take one gradient-descent step on $f(x, y) = x^2 + 3y^2$ from the point $(2, 1)$ with learning rate $\eta = 0.1$.

      1. Gradient: $\nabla f = (2x, 6y) = (4, 6)$ at $(2, 1)$.

      Vectors: lists of numbers that are also arrows

      A vector is an ordered list of numbers, and the dot product of two vectors measures how much they point the same way.

      Every data point in machine learning is a vector. Distances between vectors drive k-means, k-NN and clustering; dot products drive SVMs, PCA and neural networks. You’ll use these few operations in nearly every ML question.

      Why lists? To compare two players fairly you want all their numbers at once, not one at a time; to describe a data point with 30 features you need 30 numbers kept in order. A vector is exactly that.

      A vector in $\R^n$ (read “R n”: lists of $n$ real numbers) is a list of $n$ real numbers, written as a column: $\v = \begin{bmatrix}3\\1\end{bmatrix}$. In two dimensions you can draw it as an arrow from the origin to the point $(3, 1)$. In 3 or 100 dimensions you can’t draw it, but every rule below still works.

      • Add entry by entry: $\begin{bmatrix}3\\1\end{bmatrix} + \begin{bmatrix}1\\2\end{bmatrix} = \begin{bmatrix}4\\3\end{bmatrix}$. As arrows: place the second at the tip of the first.
      • Scale by a number: $2\v = \begin{bmatrix}6\\2\end{bmatrix}$, the same direction and twice as long. A negative number flips the direction.
      • Length (norm): $\norm{\v} = \sqrt{v_1^2 + v_2^2 + \cdots + v_n^2}$. This is Pythagoras: $\norm{(3,4)} = 5$.
      • A unit vector has length 1. Dividing any non-zero vector by its length gives a unit vector in the same direction (“normalising”).

      A little trigonometry first

      The dot product below mentions $\cos\theta$, the cosine of the angle $\theta$ between two arrows. You only need its behaviour, not its triangle definition: $\cos 0^\circ = 1$ (arrows point the same way), $\cos 60^\circ = 0.5$, $\cos 90^\circ = 0$ (arrows at right angles), $\cos 180^\circ = -1$ (arrows point opposite ways).       Projection and distance

      The projection of $\u$ onto $\v$ is the part of $\u$ that points along $\v$: $\displaystyle \text{proj}_{\v}\u = \frac{\u\cdot\v}{\v\cdot\v}\,\v$. It’s the foundation of least squares, PCA and projection matrices in the linear-algebra module.

      Two common ways to measure the distance between points $\x$ and $\y$:

      • Euclidean (straight line): $\norm{\x - \y} = \sqrt{\sum (x_i - y_i)^2}$.
      • Manhattan (city blocks): $\sum |x_i - y_i|$, as if you could only walk along streets.

        Think of a matrix as an action: “swap, then stretch” is usually different from “stretch, then swap”.

      • Identity $I$: 1s on the diagonal, 0s elsewhere. $I\x = \x$ and $AI = IA = A$.
