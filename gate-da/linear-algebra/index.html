    Span and subspaces: flat things through the origin

    The span of some vectors is everything you can build from them by scaling and adding; a subspace is a set that's closed under exactly those operations, which in pictures means a line, plane or higher-dimensional flat sheet through the origin.

    "Which of these are subspaces?" is a standard GATE MSQ. Null spaces and column spaces (the next part) are subspaces, and so is everything PCA projects onto.

    It's like a recipe book that only allows "double this, add that". Starting from a few ingredients, the span is every dish you can make, and you can never cook your way out of it.

    A linear combination of vectors $\v_1, \ldots, \v_k$ is any $c_1\v_1 + \cdots + c_k\v_k$ with real numbers $c_i$. The span is the set of all such combinations.

    • One non-zero vector in $\R^2$ spans a line through the origin.
    • Two vectors in $\R^2$ that don't lie on the same line span the whole plane.
    • Two such vectors in $\R^3$ span a plane through the origin, not all of space.

    Think of the Hyderabad Hyperplanes' season as runs and wickets per match. "Two batting performances plus half a bowling performance" is a linear combination of the two performance vectors.

    A set $W \subseteq \R^n$ is a subspace if

    1. it contains the zero vector $\0$;
    2. it's closed under addition: $\u, \v \in W \Rightarrow \u + \v \in W$;
    3. it's closed under scaling: $\v \in W,\ c\in\R \Rightarrow c\v \in W$.

    Every span is a subspace, and every subspace is the span of some vectors.

    • Contains 0? If not, stop: not a subspace. ($5x_1 + 2x_3 + 4 = 0$ fails: plugging in $\0$ gives $4 = 0$.)
    • Defined by homogeneous linear equations ("$= 0$", no constants, no squares)? Then yes: it's a null space.
    • Defined as all combinations $\alpha\u + \beta\v$ with $\alpha, \beta$ free? Yes: it's a span.
    • Squares, absolute values, products, or sign restrictions (like $x \ge 0$ or $\alpha^2$)? Almost always no: scaling by −1 breaks it.

    Independence, basis and dimension: no redundant directions

    Vectors are linearly independent when none of them can be built from the others; a basis is an independent set that spans the whole space, and the number of vectors in it is the dimension.

    Independence underlies rank, invertibility and solution counts. GATE asks about it directly ("orthonormal vectors are independent?") and through rank and determinant questions.

    It's like a squad with no duplicate skills: each player adds something the others can't cover. A basis is the smallest squad that can still play every role.

    Vectors $\v_1, \ldots, \v_k$ are linearly independent if the only way to get $c_1\v_1 + \cdots + c_k\v_k = \0$ is with every $c_i = 0$. Otherwise they're dependent: one of them is a combination of the others.

    • Two vectors are dependent exactly when one is a multiple of the other (they lie on one line).
    • Any set containing $\0$ is dependent ($1\cdot\0 = \0$).
    • More than $n$ vectors in $\R^n$ are always dependent: there just aren't enough directions.
    • For $n$ vectors in $\R^n$: put them as columns of a matrix $A$. They're independent ⇔ $\det A \ne 0$ ⇔ $A$ is invertible.

    A basis of a subspace $W$ is a set of independent vectors that spans $W$. Every basis of $W$ has the same number of vectors: the dimension of $W$. Each vector in $W$ is a unique combination of basis vectors; those coefficients are its coordinates in that basis. $\R^n$ has dimension $n$; its standard basis is $\e_1 = (1, 0, \ldots, 0), \ldots, \e_n$.

    Vectors are orthonormal if each has length 1 and every pair is perpendicular: $\v_i\cdot\v_j = 0$ for $i \ne j$, $\v_i\cdot\v_i = 1$. Orthonormal vectors are automatically independent: dot $c_1\v_1 + \cdots + c_k\v_k = \0$ with $\v_j$ and everything vanishes except $c_j = 0$.

    Go deeper: the Gram matrix (2025 Q38)

    Put $\x_1, \ldots, \x_n$ as the columns of $X$. The matrix $A = X\T X$ has entries $A_{ij} = \x_i\cdot\x_j$ (the "Gram matrix").     Gaussian elimination: solving equations systematically

    Gaussian elimination solves $A\x = \b$ by adding multiples of one equation to another until the system is triangular, then solving from the bottom up.

    It's in the syllabus by name, GATE has asked about its cost, and its by-products (pivots, echelon form) give you rank, determinant and LU decomposition for free.

    It's like untangling earphones one knot at a time: each step simplifies one thing without undoing the last, until the answer just falls out.

    Directly in cost and procedure questions; indirectly every time you need a rank or a solution count.

    Take the system $x + 2y = 5$, $3x - y = 1$. In matrix form:

    $$\begin{bmatrix}1&2\\3&-1\end{bmatrix}\begin{bmatrix}x\\y\end{bmatrix} = \begin{bmatrix}5\\1\end{bmatrix}.$$

    Two ways to see it:

    • Row picture: each equation is a line; the solution is where the lines meet.
    • Column picture: find weights $x, y$ so that $x\begin{bmatrix}1\\3\end{bmatrix} + y\begin{bmatrix}2\\-1\end{bmatrix} = \begin{bmatrix}5\\1\end{bmatrix}$. A solution exists exactly when $\b$ is in the span of the columns.
    1. Write the augmented matrix $[A \mid \b]$.
    2. Use three row operations, none of which changes the solutions: swap two rows; multiply a row by a non-zero number; add a multiple of one row to another.
    3. Working column by column, use the pivot (the first non-zero entry of the current row) to create zeros below it. The result is row echelon form: a staircase of pivots with zeros below.
    4. Back-substitute: solve the last equation, plug into the one above, and so on.

    How much work is it?

    Eliminating below one pivot in an $n\times n$ matrix touches about $n^2$ entries, and there are $n$ pivots, so elimination costs on the order of $n^3$ operations. Back-substitution on a triangular system is cheaper: row $k$ needs about $k$ multiplications, totalling about $n^2/2$, so $O(n^2)$.

    Rank and nullity: predicting how many solutions exist

    The rank of a matrix is the number of independent directions its columns span; the nullity is the number of independent directions it squashes to zero; they always add up to the number of columns.

    Rank decides whether $A\x = \b$ has no, one or infinitely many solutions. GATE asks this every year in some form, often as an MSQ about matrices of particular shapes.

    It's like a camera taking a 2-D photo of a 3-D scene: the photo's dimension is the rank (2), and the direction straight away from the lens, which gets lost entirely, is the null space (dimension 1). 2 + 1 = 3.

    For an $m\times n$ matrix $A$:

    • Column space $C(A)$: span of the columns, a subspace of $\R^m$. Its dimension is the rank $r$ = the number of pivots in echelon form.
    • Null space $N(A) = \{\x : A\x = \0\}$, a subspace of $\R^n$. Its dimension is the nullity = the number of free variables.
    • The row space (span of the rows) also has dimension $r$: row rank = column rank.

    $$\mathrm{rank}(A) + \mathrm{nullity}(A) = n\ \ (\text{the number of columns}).$$ Every column is either a pivot column or a free one.

    • No solution if $\b$ is not in $C(A)$, i.e. $\mathrm{rank}[A\mid\b] \gt \mathrm{rank}(A)$.
    • If a solution exists: unique when $r = n$ (no free variables), infinitely many when $r \lt n$.
    • Every solution = one particular solution + anything in the null space.
    • So: if $A\x = \b$ has a unique solution for some $\b$, then $N(A) = \{\0\}$ and it can never have infinitely many for any $\b$.

    The four fundamental subspaces. Row space ⟂ null space (in $\R^n$), and column space ⟂ left null space $N(A\T)$ (in $\R^m$). "⟂" means every vector of one is perpendicular to every vector of the other. Why: $A\x = \0$ says $\x$ is dotted to zero with every row.

    Square matrices. For $n\times n$ $A$, these are all equivalent: rank $n$; columns independent; $N(A) = \{\0\}$; $\det A \ne 0$; $A$ invertible; $A\x = \b$ has exactly one solution for every $\b$.

    Determinants: how much a matrix scales area

    The determinant of a square matrix is the factor by which it scales area (2-D) or volume (3-D), with a minus sign if it flips orientation; zero means the matrix squashes space flat.

    Determinants are the fastest invertibility test, and the product rule $\det(AB) = \det A\det B$ turns scary-looking GATE questions into one-liners.

    It's like a photocopier's zoom setting: 200% doubles lengths and quadruples area. The determinant is the area factor; a determinant of 0 is a copier that prints everything onto a single line.

    Eigenvectors: the directions a matrix only stretches

    An eigenvector of $A$ is a non-zero vector that $A$ maps onto its own line, $A\v = \lambda\v$, and the eigenvalue $\lambda$ is the stretch factor.

    Eigenvalue questions appear in every GATE DA paper, usually solvable in seconds with the trace and determinant shortcuts. They're also the maths behind PCA, Fisher's discriminant and the stability of gradient descent.

    It's like spinning a globe: almost every point moves, but the points on the axis stay on the axis. Those axis directions are the globe's eigenvectors.

    Where it shows up in GATE DA

    Every paper, often several questions. The trace/determinant tricks alone solve about half of them.

    A number $\lambda$ and a non-zero vector $\v$ with $$A\v = \lambda\v.$$ Rewrite as $(A - \lambda I)\v = \0$: a non-zero solution exists exactly when $A - \lambda I$ is singular, i.e. $$\det(A - \lambda I) = 0\quad(\text{the characteristic equation}).$$ For an $n\times n$ matrix it's a degree-$n$ polynomial in $\lambda$, so there are $n$ eigenvalues counted with repetition (possibly complex).

    • Trace = sum of eigenvalues; determinant = product of eigenvalues.
    • For 2 × 2: the characteristic equation is $\lambda^2 - (\mathrm{tr}A)\lambda + \det A = 0$. Discriminant $(\mathrm{tr}A)^2 - 4\det A \lt 0$ ⇒ complex pair.
    • Triangular (or diagonal) matrix: eigenvalues are the diagonal entries.
    • Same eigenvectors, new eigenvalues: $A^k \to \lambda^k$, $A^{-1} \to 1/\lambda$, $A + cI \to \lambda + c$, any polynomial $p(A) \to p(\lambda)$.
    • $A$ is singular ⇔ 0 is an eigenvalue.
    • A real matrix's complex eigenvalues come in conjugate pairs $a \pm bi$.
    • Eigenvectors for different eigenvalues are linearly independent.

    Finding eigenvectors

    Once you have $\lambda$, solve $(A - \lambda I)\v = \0$: the eigenvectors are the null space of $A - \lambda I$ (minus the zero vector). For $A = \begin{bmatrix}3&-1\\-1&3\end{bmatrix}$: trace 6, det 8, so $\lambda^2 - 6\lambda + 8 = 0$ and $\lambda = 2, 4$. For $\lambda = 4$: $A - 4I = \begin{bmatrix}-1&-1\\-1&-1\end{bmatrix}$, so $v_1 + v_2 = 0$, giving $\v = (1, -1)$. For $\lambda = 2$: $\v = (1, 1)$.

    Diagonalisation. If $A$ has $n$ independent eigenvectors (columns of $P$) with eigenvalues on the diagonal of $D$, then $A = PDP^{-1}$ and $A^k = PD^kP^{-1}$. Powers of $A$ become powers of numbers.

    Building projection matrices

    • Onto the line through $\u$: $P = \dfrac{\u\u\T}{\u\T\u}$. If $\u$ is a unit vector, just $P = \u\u\T$.
    • Onto the span of orthonormal vectors $\u_1, \ldots, \u_k$: $P = \u_1\u_1\T + \cdots + \u_k\u_k\T$, a projection of rank $k$.
    • Onto the column space of any $A$ with independent columns: $P = A(A\T A)^{-1}A\T$. This is least-squares regression in matrix form.

    Why eigenvalues 0 and 1: if $P\v = \lambda\v$, then $P^2\v = \lambda^2\v$. But $P^2 = P$, so $\lambda^2 = \lambda$, giving $\lambda \in \{0, 1\}$. Vectors in the target subspace have $\lambda = 1$ (unchanged); vectors perpendicular to it have $\lambda = 0$ (crushed). The same argument shows $A^3 = A$ forces $\lambda \in \{-1, 0, 1\}$.

    The centering matrix $C = I - \frac1n\mathbf 1\mathbf 1\T$ subtracts the mean from a data vector: $C\x = \x - \bar x\mathbf 1$. It's the projection onto vectors whose entries sum to zero: symmetric, idempotent, rank $n - 1$, trace $n - 1$.

    Partitioned (block) matrices

    You can cut a matrix into blocks and multiply block by block, exactly as if the blocks were numbers, provided the sizes match up:

    SVD: every matrix is rotate, stretch, rotate

    Any matrix (square or not) can be written $A = U\Sigma V\T$: rotate by $V\T$, stretch along the axes by the singular values in $\Sigma$, rotate by $U$. The singular values measure how much $A$ stretches space in its strongest directions.

    GATE has asked for singular values directly (2024 Q61) and alongside eigenvalues (2025 Q50). SVD is also how PCA is computed in practice and how data is compressed.

    It's like describing any squash-and-twist of a rubber circle: whatever you did, the circle becomes an ellipse. The SVD names the ellipse's axes (directions) and their lengths (singular values).
