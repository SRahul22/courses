M5 · Unconstrained algorithms: line search, GD, Newton, CG

Chapters 2–4 · about 60 min (15 read sections 1–2, 35 practice, 10 self-test) · Goal: given a quadratic, you can find the gradient-descent step range and rate, do an exact-line-search step and two CG steps by hand, count CG steps from eigenvalues, check Armijo/Wolfe for a given α, do one Newton step, and fill in the expanding-subspace proof steps.

Notation used everywhere (same as Quiz 2 and Midterm 1): $f(x)=\tfrac12 x^TQx-b^Tx$, $Q=Q^T\succ0$, $g_k=\nabla f(x_k)=Qx_k-b$, $x^*=Q^{-1}b$, error $e_k=x_k-x^*$ so $g_k=Qe_k$. Eigenvalues $0\lt\lambda_1\le\dots\le\lambda_n$, condition number $\kappa=\lambda_n/\lambda_1$. Careful: Quiz 2 uses $E(x)=\|x-x^*\|_Q^2$ (no ½), the Ch 3 notes use $E(x)=\tfrac12\|x-x^*\|_Q^2=f(x)-f(x^*)$. Read which one a question uses.

1. Must remember

Memorise cold: line search (Ch 2)
  • Descent direction: $\nabla f(x_k)^Td_k\lt0$. Exact step on a quadratic along any $d_k$: $\alpha_k=-\dfrac{g_k^Td_k}{d_k^TQd_k}$; for steepest descent $d_k=-g_k$: $\alpha_k=\dfrac{g_k^Tg_k}{g_k^TQg_k}$.
  • Write $\phi(\alpha)=f(x_k+\alpha d_k)$, so $\phi'(0)=\nabla f(x_k)^Td_k\lt0$. With $0\lt c_1\lt c_2\lt1$:
    Armijo (sufficient decrease): $\phi(\alpha)\le\phi(0)+c_1\alpha\phi'(0)$.
    Wolfe = Armijo + curvature $\phi'(\alpha)\ge c_2\phi'(0)$.
    Strong Wolfe = Armijo + $|\phi'(\alpha)|\le c_2|\phi'(0)|$.
    Goldstein ($0\lt c\lt\tfrac12$): $\phi(0)+(1-c)\alpha\phi'(0)\le\phi(\alpha)\le\phi(0)+c\,\alpha\phi'(0)$.
    Backtracking: try $\alpha=1,s,s^2,\dots$ ($0\lt s\lt1$), accept the first that passes Armijo.
  • Golden section: interior points at fraction $\rho=\frac{3-\sqrt5}{2}\approx0.382$ from each end; the interval shrinks by $1-\rho=\frac{\sqrt5-1}{2}\approx0.618$ per new evaluation (one old point is reused).
  • 1-D Newton: $x_{k+1}=x_k-f'(x_k)/f''(x_k)$. Needs $f''\gt0$, and can still fail far away.
  • Zoutendijk: strong Wolfe + $f$ bounded below + $\nabla f$ Lipschitz ⇒ $\sum_k\cos^2\theta_k\|\nabla f(x_k)\|^2\lt\infty$, $\cos\theta_k=\frac{-\nabla f_k^Td_k}{\|\nabla f_k\|\|d_k\|}$. If $\cos\theta_k\ge\delta\gt0$ then $\|\nabla f(x_k)\|\to0$. $d_k=-D_k\nabla f_k$ with eig$(D_k)\in[m,M]$ gives $\cos\theta_k\ge m/M$.
Memorise cold: gradient descent and Newton (Ch 3)
  • Fixed step: $e_{k+1}=(I-\alpha Q)e_k$; eigen-mode $i$ is multiplied by $(1-\alpha\lambda_i)$ each step.
  • Converges from every $x_0$ ⇔ $|1-\alpha\lambda_i|\lt1\ \forall i$ ⇔ $\boxed{0\lt\alpha\lt 2/\lambda_{\max}}$. Best $\alpha=\dfrac{2}{\lambda_{\min}+\lambda_{\max}}$, worst-case factor $\dfrac{\kappa-1}{\kappa+1}$ on $\|e_k\|$.
  • Multiplier $=-1$ ⇒ that mode flips sign forever (2-cycle). $|{\cdot}|\gt1$ ⇒ diverges, unless $e_0$ has zero component in that eigen-direction (then converges along the other eigen-lines only).
  • Exact line search SD: $f(x_{k+1})-f^*\le\left(\dfrac{\kappa-1}{\kappa+1}\right)^2(f(x_k)-f^*)$ (Kantorovich). Consecutive gradients are orthogonal ⇒ zigzag. If $g_0$ lives only in some eigen-directions, use the effective $\kappa=\lambda_{\max}/\lambda_{\min}$ over those directions only.
  • A gradient step with $\eta=1/\lambda$ kills the $\lambda$-component exactly ($1-\lambda/\lambda=0$).
  • Newton: $H_kp_k=-g_k$, $x_{k+1}=x_k+p_k$. One step on a quadratic with $Q\succ0$ lands on $x^*$. Quadratic convergence $\|e_{k+1}\|\le C\|e_k\|^2$ only for $x_0$ sufficiently close. Descent iff $H_k\succ0$ ($g_k^Tp_k=-p_k^TH_kp_k$). Damped Newton + Armijo ($c_1\lt\frac12$, start at $\alpha=1$) eventually accepts $\alpha=1$.
Memorise cold: conjugate directions / CG (Ch 4)
  • Affine-space minimum ($f$ convex): $x_S$ minimises $f$ on $\bar x+\mathrm{range}(D)$ ⇔ $D^T\nabla f(x_S)=0$. The gradient of $h(z)=f(\bar x+Dz)$ is zero; the gradient of $f$ is only orthogonal to every $d_i$, not zero.
  • Q-conjugate: $d_i^TQd_j=0$ ($i\ne j$). Nonzero Q-conjugate vectors are linearly independent (so at most $n$). Eigenvectors of $Q$ are both orthogonal and Q-conjugate.
  • Key formula: $g_i=g_0+\sum_{j\lt i}\alpha_jQd_j$. With conjugate directions: $d_i^Tg_i=d_i^Tg_0$, and $g_k\perp d_0,\dots,d_{k-1}$.
  • CG: $d_0=-g_0$; $\ \alpha_k=\dfrac{\|g_k\|^2}{d_k^TQd_k}$; $\ x_{k+1}=x_k+\alpha_kd_k$; $\ g_{k+1}=g_k+\alpha_kQd_k$; $\ \beta_k=\dfrac{\|g_{k+1}\|^2}{\|g_k\|^2}$; $\ d_{k+1}=-g_{k+1}+\beta_kd_k$.
  • $g_k^Td_k=-\|g_k\|^2$. Gradients orthogonal ($g_i^Tg_j=0$), directions Q-conjugate ($d_i^TQd_j=0$). Never swap.
  • $x_k$ minimises $f$ over $x_0+\mathrm{span}\{g_0,Qg_0,\dots,Q^{k-1}g_0\}$ (highest power $k-1$).
  • CG steps to reach $x^*$ = number of distinct eigenvalues whose eigenspaces $e_0$ actually touches ($\le n$).
  • Decrease per step: $f(x_k)-f(x_{k+1})=\dfrac{\|g_k\|^4}{2\,d_k^TQd_k}$ (the ½ is on $f$; for $E=\|x-x^*\|_Q^2$ the decrease is twice that).
  • PCG ($B\approx Q^{-1}$, SPD): $d_0=-Bg_0$, $\alpha_k=\dfrac{g_k^TBg_k}{d_k^TQd_k}$, $\beta_k=\dfrac{g_{k+1}^TBg_{k+1}}{g_k^TBg_k}$, $d_{k+1}=-Bg_{k+1}+\beta_kd_k$. Then $g_i^TBg_j=0$, $d_i^TQd_j=0$, $g_k^Td_k=-g_k^TBg_k$. Replacing $B$ by $cB$ changes nothing in $x_k$. Speed depends on eig$(B^{1/2}QB^{1/2})$.
  • Non-quadratic CG, four changes: (1) $\beta$ back to the original formula with $Q\to F(x_k)=\nabla^2f(x_k)$; (2) set $\beta_k=0$ if $d_k^TF(x_k)d_k\le0$; (3) $\alpha_k$ by a line search (no closed form); (4) check $g_k^Td_k\lt0$, else reset $d_k=-g_k$. FR + strong Wolfe ($c_2\lt\frac12$): $-\frac{1}{1-c_2}\le\frac{g_k^Td_k}{\|g_k\|^2}\le\frac{2c_2-1}{1-c_2}\lt0$.

2. Concepts

2.1 Line search: descent direction, step-size rules, golden section, Zoutendijk (Ch 2, never examined yet)

In plain words: every method in this module has the same shape: stand at $x_k$, pick a direction $d_k$ that goes downhill, then pick how far to walk ($\alpha_k$). "Downhill" means the slope along $d_k$ is negative. For the distance, you either minimise exactly along the line (possible in closed form only for quadratics) or accept any $\alpha$ that is "good enough": not too long (Armijo: you really decreased $f$) and not too short (curvature / Goldstein lower bound).

Precisely: $x_{k+1}=x_k+\alpha_kd_k$, $\phi(\alpha)=f(x_k+\alpha d_k)$, $\phi'(0)=\nabla f(x_k)^Td_k\lt0$. The rules are in the Must-remember box. Picture: the line $L_1(\alpha)=\phi(0)+c_1\alpha\phi'(0)$ is a "less steep" copy of the tangent; Armijo asks $\phi$ to be below it (caps $\alpha$ from above). Wolfe curvature asks the slope at $\alpha$ to have flattened to at least $c_2$ times the initial slope (excludes tiny $\alpha$). Strong Wolfe also forbids a large positive slope (excludes overshooting far past the minimiser). Goldstein uses a second line $\phi(0)+(1-c)\alpha\phi'(0)$ as a lower fence instead of a slope test.

Worked example (his Exercise 2.3): intervals for a quadratic $\phi$

$\phi(\alpha)=\phi(0)-p\alpha+\tfrac q2\alpha^2$, $p,q\gt0$. So $\phi'(0)=-p$, $\phi'(\alpha)=-p+q\alpha$.

  1. Exact minimiser: $\phi'(\alpha)=0\Rightarrow\alpha^*=p/q$.
  2. Armijo: $-p\alpha+\tfrac q2\alpha^2\le-c_1p\alpha\iff\alpha\le\dfrac{2(1-c_1)p}{q}$. So $\alpha\in(0,\,2(1-c_1)\alpha^*]$.
  3. Wolfe curvature: $-p+q\alpha\ge-c_2p\iff\alpha\ge(1-c_2)\alpha^*$. Wolfe interval: $[(1-c_2)\alpha^*,\ 2(1-c_1)\alpha^*]$.
  4. Strong Wolfe adds $-p+q\alpha\le c_2p\iff\alpha\le(1+c_2)\alpha^*$. Interval: $[(1-c_2)\alpha^*,\ \min\{(1+c_2),\,2(1-c_1)\}\alpha^*]$.
  5. Goldstein: $\alpha\in[2c\,\alpha^*,\ 2(1-c)\alpha^*]$. Since $c\lt\frac12$, it always contains $\alpha^*$.
  6. Lesson: ordinary Wolfe can accept steps up to almost $2\alpha^*$ (big overshoot); strong Wolfe limits the overshoot to $(1+c_2)\alpha^*$.

All five formulas checked with sympy.

Trap The Wolfe curvature condition is $\phi'(\alpha)\ge c_2\phi'(0)$ (a negative number on the right): it is a lower bound on the slope. Students write $\le$. Also: $0\lt c_1\lt c_2\lt1$ (strict), Goldstein needs $c\lt\frac12$, and for the FR theorem the notes need $c_2\lt\frac12$. He said you cannot drop either Wolfe condition in general (Section 3).

Golden section (1-D, no derivatives): keep a bracket $[a,b]$ with two interior points at $a+\rho L$ and $b-\rho L$. Compare $f$ at them, throw away the outer piece beyond the worse one. Requiring that the surviving interior point can be reused gives $\rho=(1-\rho)^2$, i.e. $\rho^2-3\rho+1=0$, $\rho=\frac{3-\sqrt5}{2}\approx0.382$. Each new evaluation multiplies the length by $0.618$. Example: on $[0,10]$ the first points are $3.82$ and $6.18$; if $f(3.82)\le f(6.18)$ the new bracket is $[0,6.18]$ and $3.82=0.618\times6.18$ is the reused right interior point.

Zoutendijk, in plain words: with strong Wolfe steps, the "useful progress" terms $\cos^2\theta_k\|\nabla f_k\|^2$ must be summable, so if your directions never become nearly perpendicular to the gradient, the gradient must go to zero. Why $d_k=-D_k\nabla f_k$ with eigenvalues of $D_k$ in $[m,M]$ is safe: $-\nabla f^Td=\nabla f^TD\nabla f\ge m\|\nabla f\|^2$ and $\|d\|\le M\|\nabla f\|$, so $\cos\theta\ge m/M\gt0$.

1-D Newton and how it fails: minimise the local quadratic model $q(x)=f(x_k)+f'(x_k)(x-x_k)+\tfrac12f''(x_k)(x-x_k)^2$: $x_{k+1}=x_k-f'(x_k)/f''(x_k)$ (same as Newton root-finding on $f'$). If $f''(x_k)\lt0$ the model is concave and the step goes towards a maximum. Even with $f''\gt0$ everywhere it can fail:

Worked example (his Exercise 2.6): $f(x)=\sqrt{1+x^2}$
  1. $f'(x)=\dfrac{x}{\sqrt{1+x^2}}$, $f''(x)=(1+x^2)^{-3/2}\gt0$: strictly convex, minimiser $x^*=0$.
  2. Newton: $x_{k+1}=x_k-\dfrac{x_k(1+x^2_k)^{-1/2}}{(1+x_k^2)^{-3/2}}=x_k-x_k(1+x_k^2)=-x_k^3$.
  3. $|x_0|\lt1$: converges to 0 extremely fast ($0.5\to-0.125\to0.00195\to\dots$). $|x_0|=1$: cycles $1,-1,1,\dots$. $|x_0|\gt1$: diverges ($1.5\to-3.375\to38.4\to\dots$).
  4. For $|x|\gt1$ the Newton direction is still downhill (sign of $-f'$), but the full step overshoots and increases $f$. A line search (damping) fixes this.

2.2 Fixed-step gradient descent on a quadratic (Midterm 1 Q II)

In plain words: on a quadratic the error splits into independent pieces, one per eigenvector of $Q$. Each step multiplies the piece along eigenvalue $\lambda_i$ by the number $1-\alpha\lambda_i$. Everything (convergence, cycling, divergence, best step) is read off from these numbers.

Precisely: $x_{k+1}=x_k-\alpha g_k$ and $g_k=Qe_k$ give $e_{k+1}=(I-\alpha Q)e_k$ (also $g_{k+1}=(I-\alpha Q)g_k$). Write $e_0=\sum_ic_iq_i$; then $e_k=\sum_i(1-\alpha\lambda_i)^kc_iq_i$ and $\|e_{k+1}\|\le\max_i|1-\alpha\lambda_i|\,\|e_k\|$.

  • All modes shrink for every start ⇔ $-1\lt1-\alpha\lambda_i\lt1$ for all $i$ ⇔ $0\lt\alpha\lt2/\lambda_{\max}$. Endpoints: at $\alpha=0$ nothing moves; at $\alpha=2/\lambda_{\max}$ the top mode has multiplier $-1$ and oscillates.
  • The worst factor $\max\{|1-\alpha\lambda_1|,|1-\alpha\lambda_n|\}$ is smallest when $1-\alpha\lambda_1=-(1-\alpha\lambda_n)$: $\alpha_{\rm opt}=\frac{2}{\lambda_1+\lambda_n}$, factor $\frac{\lambda_n-\lambda_1}{\lambda_n+\lambda_1}=\frac{\kappa-1}{\kappa+1}$ (on $\|e\|$; square it for $f-f^*$).
  • For $\alpha\gt2/\lambda_{\max}$: diverges from a general start, but converges from starts with $e_0$ inside the span of the eigenvectors whose multipliers have $|{\cdot}|\lt1$ (an "eigen-line" in 2-D).
  • Adding $b^Tx$ (shifting the minimiser) changes nothing: the Hessian, hence the range, is the same.
Worked example (his Ch 3 Exercise 1)

$f(x)=3(x_1^2+x_2^2)+4x_1x_2+5x_1+6x_2+7$. Find the largest $\alpha$ range for global convergence of $x_{k+1}=x_k-\alpha\nabla f(x_k)$.

  1. Hessian $Q=\begin{pmatrix}6&4\\4&6\end{pmatrix}$ (the $4x_1x_2$ term gives off-diagonal 4, not 2: $\partial^2/\partial x_1\partial x_2$ of $4x_1x_2$ is 4).
  2. Eigenvalues: $6\pm4$, i.e. $\lambda=2$ (eigvec $(1,-1)$), $\lambda=10$ (eigvec $(1,1)$).
  3. Range: $0\lt\alpha\lt2/10=\boxed{1/5}$.
  4. Best step $\alpha=2/(2+10)=1/6$; multipliers $1-2/6=2/3$ and $1-10/6=-2/3$; factor $2/3=(\kappa-1)/(\kappa+1)$ with $\kappa=5$.

Colour key: blue = slow mode λ=2, red = fast mode λ=10, wide gold band = worst-case envelope (it follows blue up to α = 1/6, then red). Dashed horizontal line = factor 1; to the right of α = 0.2 the red mode exceeds 1 and the iteration diverges.

Trap The bound is set by the largest eigenvalue ($2/\lambda_{\max}$), the rate by the ratio. And: objective values converging (e.g. constant $f=4$ in a 2-cycle) does not mean the iterates converge (Midterm 1 II(3)).

2.3 Steepest descent with exact line search, effective κ, reciprocal steps (Midterm 1 Q III)

In plain words: instead of a fixed $\alpha$, pick the best $\alpha$ along $-g_k$ each time. You land where the line touches a level ellipse, so the new gradient is perpendicular to the old one: the path zigzags. The guaranteed reduction in $f-f^*$ per step is $((\kappa-1)/(\kappa+1))^2$, so it is slow when $\kappa$ is large.

Precisely: $\alpha_k=\frac{g_k^Tg_k}{g_k^TQg_k}$, $g_{k+1}^Tg_k=0$, and with $E_k=f(x_k)-f^*=\frac12e_k^TQe_k$: $$E_{k+1}=\Big[1-\frac{(g_k^Tg_k)^2}{(g_k^TQg_k)(g_k^TQ^{-1}g_k)}\Big]E_k\le\Big(\frac{\kappa-1}{\kappa+1}\Big)^2E_k .$$ Effective condition number: if $g_k$ lies in an invariant subspace spanned by some eigenvectors (index set $J$), then every later $g$ stays there ($g_{k+1}=(I-\alpha_kQ)g_k$ and $I-\alpha Q$ has the same eigenvectors), so replace $\lambda_1,\lambda_n$ by the min and max eigenvalue over $J$. Reciprocal steps: a gradient step with $\eta=1/\mu$ multiplies the $\mu$-component by $1-\mu/\mu=0$. Two such steps with $\eta_0=1/\lambda_1$, $\eta_1=1/\lambda_2$ (either order) remove two known outlier eigenvalues; the product polynomial $p(t)=(1-\eta_0t)(1-\eta_1t)$ has roots $\lambda_1,\lambda_2$. No eigenvectors needed.

Worked example: the worst case is attained

$Q=\mathrm{diag}(1,4)$, $b=0$ (so $x^*=0$, $f^*=0$), $x_0=(4,1)$.

  1. $g_0=Qx_0=(4,4)$, $g_0^Tg_0=32$, $g_0^TQg_0=16+64=80$, $\alpha_0=32/80=2/5$.
  2. $x_1=(4,1)-\tfrac25(4,4)=(12/5,\,-3/5)$; $g_1=(12/5,-12/5)$, and $g_1^Tg_0=0$ ✓ (zigzag).
  3. $f(x_0)=\frac12(16+4)=10$, $f(x_1)=\frac12(5.76+1.44)=3.6$. Ratio $3.6/10=9/25$.
  4. Kantorovich bound with $\kappa=4$: $(3/5)^2=9/25$. Equal: this start is a worst case. Next step: $x_2=(36/25,9/25)=\frac{9}{25}x_0$, so the zigzag repeats with ratio $9/25$ forever.
Trap SD exact line search reaches $x^*$ in one step iff $g_0$ is an eigenvector of $Q$ (his Ch 3 Ex 2). The Kantorovich factor is for $f-f^*$ (or $\|e\|_Q^2$); for $\|e\|_Q$ take the square root.

2.4 The $\|x\|^p/p$ family: when the gradient is not Lipschitz (Midterm 1 Q V, "modification of exercise 7")

In plain words: for $1\lt p\lt2$, $f_p(x)=\frac1p\|x\|^p$ has a V-ish bottom: differentiable at 0 with gradient 0, but the gradient changes infinitely fast there. So a fixed step is always "too long" near the minimiser and pushes you away. Exercise 7 in his Ch 3 set is $p=3/2$.

Precisely: $\nabla f_p(x)=\|x\|^{p-2}x$ for $x\ne0$, $\nabla f_p(0)=0$; $\|\nabla f_p(x)\|/\|x\|=\|x\|^{p-2}\to\infty$ as $x\to0$, so no Lipschitz $L$ near 0. Fixed step: $x_{k+1}=(1-\alpha r_k^{p-2})x_k$ with $r_k=\|x_k\|$, so $r_{k+1}=r_k|1-\alpha r_k^{p-2}|$.

  • $f$ increases ⇔ $\alpha r_k^{p-2}\gt2$ ⇔ $0\lt r_k\lt(\alpha/2)^{1/(2-p)}$ (too close to 0 ⇒ thrown out).
  • $r_0=(\alpha/2)^{1/(2-p)}$: multiplier $-1$, iterates $x_0,-x_0,x_0,\dots$.
  • $r_0=\alpha^{1/(2-p)}$: multiplier 0, lands on 0 in one step. Convergence to 0 can only happen by hitting 0 exactly (finite termination) or not at all.
  • Exact line search along $-\nabla f_p$: $\alpha_k=r_k^{2-p}$, lands exactly on 0.

Numerical check ($p=1.5$, $\alpha=0.3$): $r_c=0.0225$ gives the ±2-cycle; $r=0.09$ hits 0 in one step; starting at $r=0.001$ the norm climbs to 0.0225 and sticks in the cycle.

2.5 Newton's method (n-D, never examined yet)

In plain words: replace $f$ by its second-order Taylor model at $x_k$ and jump to the model's minimiser. On a quadratic the model is exact, so one step is enough. On a general function this is superb near a minimiser with PD Hessian (the number of correct digits roughly doubles each step) and unreliable far away.

Precisely: $m_k(p)=f(x_k)+g_k^Tp+\frac12p^TH_kp$, $H_kp_k=-g_k$, $x_{k+1}=x_k+p_k$ (solve the system, do not form $H^{-1}$). Quadratic $f$, $Q\succ0$: $x_1=x_0-Q^{-1}(Qx_0-b)=Q^{-1}b=x^*$. Theorem: if $\nabla f(x^*)=0$, $\nabla^2f(x^*)$ nonsingular and the Hessian is Lipschitz near $x^*$, then for $x_0$ sufficiently close $\|x_{k+1}-x^*\|\le C\|x_k-x^*\|^2$. Descent: $g_k^Tp_k=-p_k^TH_kp_k\lt0$ when $H_k\succ0$; if $H_k$ is indefinite the Newton direction may point uphill and no amount of damping fixes a non-descent direction. Damped Newton: $x_{k+1}=x_k+\alpha_kp_k$ with Armijo backtracking from $\alpha=1$; near a minimiser with $\nabla^2f(x^*)\succ0$ (and $c_1\lt\frac12$) the full step $\alpha=1$ is eventually accepted, so the fast local rate comes back. Damped Newton = steepest descent in coordinates scaled by $H_k^{-1/2}$.

Worked example: Newton on a quadratic

$f(x)=x_1^2+x_1x_2+x_2^2-3x_1$: $Q=\begin{pmatrix}2&1\\1&2\end{pmatrix}$, $b=(3,0)$. From any $x_0$, e.g. $x_0=(0,0)$: $g_0=(-3,0)$, solve $Qp=(3,0)$: $p=(2,-1)$. $x_1=(2,-1)$, and $\nabla f(x_1)=(4-1-3,\,2-2)=(0,0)$ ✓. One step, as promised.

2.6 Affine-space minimum, Q-conjugacy, expanding subspace (Midterm 1 Q VI)

In plain words: if you may only move inside a flat sheet $\bar x+\mathrm{span}\{d_1,\dots,d_L\}$, you are at the best point of the sheet when no direction inside the sheet goes downhill, i.e. the gradient is perpendicular to the sheet. Conjugate directions are the special directions for which "minimise along $d_0$, then along $d_1$, …" gives the same answer as minimising over the whole sheet at once, because the later line searches never spoil the earlier ones.

Precisely: $h(z)=f(\bar x+Dz)$, $\nabla h(z)=D^T\nabla f(\bar x+Dz)$, $\nabla^2h=D^T\nabla^2fD$. For convex $f$: minimiser ⇔ $D^T\nabla f(x_S)=0$. For the quadratic: $(D^TQD)z_S=-D^T\nabla f(\bar x)$ (an $m\times m$ PD system). After one exact line search along $d$: $d^Tg_{k+1}=0$.

Expanding-subspace chain (memorise the order; Midterm 1 VI asked exactly these steps): with $c_i=d_i^Tg_0$, $h_i=d_i^TQd_i$,

  1. $\Phi(\beta)=f(x_0+\sum\beta_id_i)=f(x_0)+\sum_i\big(c_i\beta_i+\tfrac12h_i\beta_i^2\big)$ (cross terms die by conjugacy).
  2. Each $h_i\gt0$ ($Q\succ0$, $d_i\ne0$), so each scalar piece has a unique minimiser $\beta_i^*=-c_i/h_i$.
  3. Key formula $g_i=g_0+\sum_{j\lt i}\alpha_jQd_j$ ⇒ $d_i^Tg_i=c_i$ (earlier steps do not change the slope along $d_i$).
  4. Line search: $\alpha_i=-d_i^Tg_i/h_i=-c_i/h_i=\beta_i^*$.
  5. Hence $x_K=x_0+\sum\beta_i^*d_i$ = the minimiser over $x_0+\mathcal S_K$, and $g_K\perp\mathcal S_K$. The order of the directions does not matter. For $K=n$ this is $x^*$.
Worked example: making a direction conjugate (Quiz 2 Q3)

$Q=\begin{pmatrix}3&1\\1&2\end{pmatrix}$, $d_0=(1,0)$, $d_1=(s,1)$. $d_0^TQd_1=(3,1)\cdot(s,1)=3s+1=0\Rightarrow s=-\frac13$. Note $d_0^Td_1=-\frac13\ne0$: conjugate but not orthogonal.

Trap (his warning) At the affine minimiser, $\nabla h=0$ but $\nabla f\ne0$ in general. Writing "$\nabla f(x_S)=0$" is the mistake he warned about. Also: Q-conjugate ⇒ linearly independent, but Q-conjugate directions are generally not orthogonal; eigenvectors of $Q$ are both.

2.7 The CG algorithm, its identities, and how many steps it needs

In plain words: CG builds the conjugate directions on the fly: take the new steepest-descent direction and add just enough of the previous direction to make it conjugate. Because of conjugacy, step $k$ gives the best point in a growing space; on an $n$-D quadratic it finishes in at most $n$ steps, and fewer if the starting error only involves a few distinct eigenvalues.

Precisely: the algorithm is in the Must-remember box. Original forms: $\alpha_k=-\frac{d_k^Tg_k}{d_k^TQd_k}$ and $\beta_k=\frac{g_{k+1}^TQd_k}{d_k^TQd_k}$ (from $d_{k+1}^TQd_k=0$); with exact line search they become $\frac{\|g_k\|^2}{d_k^TQd_k}$ and $\frac{\|g_{k+1}\|^2}{\|g_k\|^2}$ because $g_k^Td_k=-\|g_k\|^2$ and $g_{k+1}^Tg_k=0$. CG theorem: $\mathrm{span}\{g_0..g_k\}=\mathrm{span}\{d_0..d_k\}=\mathrm{span}\{g_0,Qg_0,..,Q^kg_0\}$, $d_k^TQd_i=0$ ($i\lt k$).

Polynomial view: $x_k-x^*=r_k(Q)e_0$ with $r_k$ a degree-$k$ polynomial, $r_k(0)=1$, and CG picks the one minimising $E=\sum_\ell y_\ell^2\lambda_\ell r(\lambda_\ell)^2$. Consequences: (i) if $e_0$ touches exactly $r$ distinct eigenvalues, $r(t)=\prod(1-t/\mu_j)$ kills them, so CG stops in exactly $r$ steps; (ii) partial CG bound: if $m$ outlier eigenvalues lie above an interval $[a,b]$, after $m+1$ steps $E_{\rm after}\le\big(\frac{b-a}{b+a}\big)^2E_{\rm before}$ (use $r(t)=(1-\frac{2t}{a+b})\prod(1-t/\mu_j)$ and bound the outlier factors by 1 on $[a,b]$).

2.8 Preconditioned CG

In plain words: change variables $x=B^{1/2}y$ so the problem looks rounder (Hessian $\hat Q=B^{1/2}QB^{1/2}$ closer to a multiple of $I$), run ordinary CG on $y$, then translate the formulas back to $x$. Every "$g$" in a CG inner product becomes "$Bg$".

Precisely: $\hat g=B^{1/2}g$, so $\hat g_i^T\hat g_j=g_i^TBg_j=0$ (Euclidean $g_i^Tg_j$ is not preserved). Formulas in the Must-remember box. Scaling $B\to cB$: $\tilde d_k=cd_k$, $\tilde\alpha_k=\alpha_k/c$, $\tilde\beta_k=\beta_k$, same $x_k$; so "eigenvalues of $\hat Q$ close to 1" is not by itself the criterion, the spread (clustering) is. $B=cQ^{-1}$ ⇒ one step. Practical $B$: inverse of the diagonal of $Q$.

Trap (and a disagreement) In class he said that with PCG the original $f(x_k)$ "may not reduce monotonically" (Ch 4 lec 4 [19:30]). Mathematically, $f(x_k)=h(y_k)$ exactly (same point, $x=B^{1/2}y$), and each PCG step is an exact line search for $f$ along $d_k$, so $f(x_k)$ does decrease. What really need not decrease is the Euclidean gradient norm $\|g_k\|$. If it is asked, write this reasoning.

2.9 CG on non-quadratic functions (FR, PR)

In plain words: on a non-quadratic $f$ there is no single $Q$, so conjugacy and the $n$-step finish are lost; CG becomes a heuristic that is often faster than steepest descent. You must add safety checks.

Precisely (Hessian-based "modified original CG"): $\delta_k=d_k^TF(x_k)d_k$; trial step $\hat\alpha_k=-g_k^Td_k/\delta_k$ (minimiser of the quadratic model along $d_k$, not of $f$: the full step can increase $f$, so safeguard by Armijo); $\beta_k=\frac{g_{k+1}^TF(x_k)d_k}{\delta_k}$ if $\delta_k\gt0$, else $\beta_k=0$; reset $d_k=-g_k$ whenever $g_k^Td_k\ge0$. FR / PR (gradient-only): $\beta^{FR}_k=\frac{\|g_{k+1}\|^2}{\|g_k\|^2}$, $\beta^{PR}_k=\frac{g_{k+1}^T(g_{k+1}-g_k)}{\|g_k\|^2}$. With exact line search, any finite $\beta$ gives $g_{k+1}^Td_{k+1}=-\|g_{k+1}\|^2\lt0$ (descent, not convergence). FR + strong Wolfe with $0\lt c_1\lt c_2\lt\frac12$: $-\frac1{1-c_2}\le\frac{g_k^Td_k}{\|g_k\|^2}\le\frac{2c_2-1}{1-c_2}\lt0$.

Worked example: plug into the FR bound

$c_2=\frac14$: lower $-\frac{1}{3/4}=-\frac43$, upper $\frac{-1/2}{3/4}=-\frac23$. Both negative ⇒ every FR direction is a descent direction (Quiz 2 Q19).

S6

Write Armijo, Wolfe curvature, strong Wolfe and Goldstein in terms of $\phi(\alpha)=f(x_k+\alpha d_k)$, with the allowed constants. What does Zoutendijk say?
