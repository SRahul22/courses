1. Must remember

Memorise cold: Chapter 8 (LP, standard form $\min c^Tx,\ Ax=b,\ x\ge 0$, rank $A=m$)
  • LP KKT (Lagrangian $c^Tx+\lambda^T(b-Ax)-\mu^Tx$): $\;A^T\lambda+\mu=c,\quad Ax=b,\ x\ge0,\quad \mu\ge0,\quad \mu^Tx=0.$ ($\lambda$ free.)
  • Basis $A=[B\ N]$: $\bar x_B=B^{-1}b,\ \bar x_N=0$ (feasible iff $B^{-1}b\ge0$) · $\bar\lambda=B^{-T}c_B$ · $\bar\mu_B=0$ · $\bar\mu_N=c_N-N^T\bar\lambda$ (reduced costs).
  • Optimal if $\bar x_B\ge0$ and $\bar\mu_N\ge0$. Gap identity: $c^Tx'-c^T\bar x=\bar\mu_N^Tx'_N$ for every feasible $x'$.
  • Step: pick $q$ with $\bar\mu_q\lt0$; $u=B^{-1}a_q$; direction $d_B=-u,\ d_q=1$ (so $Ad=0$, $c^Td=\bar\mu_q$).
  • Ratio test: $\theta=\min_{i:\,u_i\gt0}(\bar x_B)_i/u_i$; cost change $=\theta\bar\mu_q$. Unbounded if $u\le0$ and $\bar\mu_q\lt0$. Degenerate ($\theta=0$ possible) iff some basic variable $=0$.
  • Theorems: extreme point $\Leftrightarrow$ BFS; feasible $\Rightarrow$ a BFS exists; optimum exists $\Rightarrow$ an optimal BFS exists. $\bar x$ is a BFS iff its positive-support columns are independent.
  • Bland: enter = smallest index with $\bar\mu_j\lt0$; leave = smallest original index among ratio ties. New $B'$ nonsingular since $\det B'=u_p\det B$, $u_p\gt0$.
Memorise cold: Chapter 9 (QP $f=\tfrac12x^TQx-c^Tx$)
  • Equality QP KKT ($\ell=f+\lambda^T(Ax-b)$): $\;Qx-c+A^T\lambda=0,\ Ax=b$, i.e. $\underbrace{\begin{bmatrix}Q&A^T\\A&0\end{bmatrix}}_{K}\begin{bmatrix}x\\\lambda\end{bmatrix}=\begin{bmatrix}c\\b\end{bmatrix}.$
  • Unique global minimiser $\iff H_r=Z^TQZ\succ0$ $\iff d^TQd\gt0$ for all $0\ne d\in\ker A$. Then $K$ is nonsingular. $Q$ need not be PD. $K$ nonsingular $\iff H_r$ nonsingular (not PD!).
  • Null-space: $x=x_p+Zz$, $\ \phi(z)=f(x_p)+g_r^Tz+\tfrac12z^TH_rz$, $g_r=Z^T(Qx_p-c)$, solve $H_rz^*=-g_r$.
  • Range-space (Schur), $Q$ nonsingular: $S=AQ^{-1}A^T$, $\ S\lambda=AQ^{-1}c-b$, $\ x=Q^{-1}(c-A^T\lambda)$. $Q\succ0\Rightarrow S\succ0$.
  • Projector: $P=I-A^T(AA^T)^{-1}A=Z(Z^TZ)^{-1}Z^T$; $r=-P\nabla f$ gives $\nabla f^Tr=-\|r\|^2$. Projected CG: at most $n-m$ steps.
  • Active set: $g_k=Qx_k-c$, $\ q_k(p)=g_k^Tp+\tfrac12p^TQp$ on $a_i^Tp=0\ (i\in W_k)$. If $p_k\ne0$: $g_k^Tp_k=-p_k^TQp_k\lt0$, $\ f(x_k+\alpha p_k)-f(x_k)=-\alpha(1-\tfrac\alpha2)p_k^TQp_k$.
  • Ratio test: $\alpha_k=\min_{i\notin W_k,\ a_i^Tp_k\gt0}\dfrac{b_i-a_i^Tx_k}{a_i^Tp_k}$; step $=\min\{1,\alpha_k\}$; if $\alpha_k\le1$ add the blocker. If $p_k=0$: solve $g_k+\sum_{W_k}\lambda_ia_i=0$; all $\lambda_i\ge0\Rightarrow$ stop (global min if $Q\succeq0$); else drop the most negative.
Sign conventions differ between the chapters Ch 8 uses $\lambda^T(b-Ax)$ so stationarity is $c=A^T\lambda+\mu$. Ch 9 uses $\lambda^T(Ax-b)$ so stationarity is $Qx-c+A^T\lambda=0$. Use the one the question states; if none is stated, say which you use.

2. Concepts

2.0 One idea, two chapters (read this first, 2 min)

In plain words: both methods guess which constraints are "tight", solve an easy equality problem with only those, and then ask two questions. (1) Can I improve by moving? If yes, move along a direction until some new constraint stops you (a ratio test). (2) If I can't improve, are the multipliers the right sign? If one is wrong, release that constraint.

The one difference: an LP objective is linear, so it never "stops in the middle" — you always walk to the blocker. A QP has curvature, so the subproblem minimiser may lie before the blocker; that is why the QP step is $\min\{1,\alpha_k\}$ and the LP step is just $\theta$.

2.1 Standard form and conversions

In plain words: every LP can be rewritten as "minimise a linear cost, equalities only, all variables $\ge0$". You add a non-negative variable to soak up the gap in each inequality, and you split a free variable into two non-negative parts.

Precisely:

  • $a_i^Tx\le b_i$ → $a_i^Tx+y_i=b_i,\ y_i\ge0$ (slack, $A'=[A\ \ I]$, cost $0$).
  • $a_i^Tx\ge b_i$ → $a_i^Tx-y_i=b_i,\ y_i\ge0$ (surplus, $A'=[A\ -I]$, cost $0$).
  • free $x_j$ → $x_j=x_j^+-x_j^-$, $x_j^\pm\ge0$, substitute in objective and constraints (the pair need not be unique).
  • $\max c^Tx$ → $\min(-c)^Tx$. Bound $x_j\ge\ell_j$ → $x_j=\ell_j+v_j$. Negative $b_i$: multiply the row by $-1$ (flips $\le$/$\ge$). The notes then assume $b\ge0$.
Worked example $\max\ 3x_1+x_2$ s.t. $x_1-x_2\le2,\ x_1+x_2\ge1,\ x_1\ge0,\ x_2$ free.
  1. Max → min: $\min\ -3x_1-x_2$.
  2. Split $x_2=x_2^+-x_2^-$: objective $-3x_1-x_2^++x_2^-$.
  3. Row 1 ($\le$): add slack $s_1$: $x_1-x_2^++x_2^-+s_1=2$. Row 2 ($\ge$): subtract surplus $s_2$: $x_1+x_2^+-x_2^--s_2=1$.
  4. Variables $(x_1,x_2^+,x_2^-,s_1,s_2)\ge0$, $n=5,\ m=2$: $$A=\begin{bmatrix}1&-1&1&1&0\\1&1&-1&0&-1\end{bmatrix},\ b=\begin{bmatrix}2\\1\end{bmatrix},\ c=(-3,-1,1,0,0)^T.$$
Trap The column of $x_2^-$ is the negative of the column of $x_2^+$, and so is its cost. Slack/surplus costs are $0$. Surplus has coefficient $-1$, not $+1$.

2.2 Basic solutions, BFS, degeneracy, extreme points, fundamental theorem

In plain words: pick $m$ independent columns (a "basis"), switch every other variable off, and solve the square system. That point is a basic solution. If it is also $\ge0$ it is a BFS. Geometrically BFSs are exactly the corners of the feasible set, and if the LP has an optimum, some corner is optimal. So simplex only needs to hop between corners.

Precisely:

  • Basic solution (Def 8.2.1.1): $B$ = nonsingular $m\times m$ submatrix of columns; $x_N=0$, $x_B=B^{-1}b$. It need not be $\ge0$.
  • BFS: basic and feasible, i.e. $B^{-1}b\ge0$. Zero basic values are allowed. Degenerate BFS: some basic variable $=0$ ($\Leftrightarrow$ fewer than $m$ positive components). $B$ is still nonsingular.
  • Support test: a feasible $\bar x$ is a BFS $\iff$ the columns $\{a_i: \bar x_i\gt0\}$ are linearly independent (extend them to a full basis using full row rank).
  • Theorem 8.2.2: $x\in K=\{Ax=b,x\ge0\}$ is an extreme point $\iff$ $x$ is a BFS.
  • Theorem 8.2.1 (fundamental theorem): (i) feasible set nonempty ⇒ a BFS exists; (ii) an optimal solution exists ⇒ an optimal BFS exists. (Not "every optimum is a BFS", and not "feasible set bounded".)

Proof ideas you must be able to write in steps (Ch 6 Problem Set 1, P11–12):

  1. Dependent support ⇒ a null direction. If $\{a_i:x_i\gt0\}$ are dependent, there is $d\ne0$ with $Ad=0$ and $d_i=0$ wherever $x_i=0$.
  2. Both $\pm d$ are feasible. $A(x\pm\varepsilon d)=b$, and for small $\varepsilon$ the positive components stay positive while zero components stay $0$.
  3. Extreme ⇒ BFS: $x=\tfrac12(x+\varepsilon d)+\tfrac12(x-\varepsilon d)$, two distinct feasible points, so $x$ is not extreme. Contrapositive.
  4. BFS ⇒ extreme: if $x=\alpha y+(1-\alpha)z$, $0\lt\alpha\lt1$, $y,z\in K$, then $y_N=z_N=0$ (non-negative numbers averaging to 0), so $By_B=Bz_B=b=Bx_B$, and nonsingular $B$ gives $y=z=x$.
  5. Reduce the support (P11): choose the sign of $d$ so some $d_i\gt0$; move to $x-\varepsilon^*d$ with $\varepsilon^*=\min_{d_i\gt0}x_i/d_i$. One positive component hits $0$, no zero component becomes positive. Repeat; it ends (support shrinks each time) at independent support = BFS.
  6. Optimal version (P12): at an optimum $x^\star$, FONC on the feasible directions $d$ and $-d$ gives $c^Td\ge0$ and $-c^Td\ge0$, so $c^Td=0$. Since the cost is linear, $c^T(x^\star-td)=c^Tx^\star$ exactly along the line, so each reduction step keeps optimality ⇒ an optimal BFS.
Worked example (slides p. 79) $\min\ -x_3$ s.t. $x_1+x_3=1,\ x_2+x_3=1,\ x\ge0$. So $a_1=(1,0)^T,\ a_2=(0,1)^T,\ a_3=(1,1)^T$.
  1. Basis $\{x_1,x_2\}$: $B=I$, $x_B=(1,1)$, point $(1,1,0)$: nondegenerate BFS.
  2. Basis $\{x_3,x_2\}$: $B=\begin{bmatrix}1&0\\1&1\end{bmatrix}$, $x_B=B^{-1}b=(1,0)$, point $(0,0,1)$: a degenerate BFS (basic $x_2=0$).
  3. The feasible point $x=(\tfrac12,\tfrac12,\tfrac12)$ has 3 positive components but only $m=2$ rows, so its support is dependent: $d=(1,1,-1)$ has $Ad=0$. Not a BFS, not a corner.
  4. Reduction: $c^Td=+1\ne0$, so this $x$ is not optimal (moving along $-d$ lowers the cost). Moving $x-td$ until $t=\tfrac12$ lands on $(0,0,1)$, the optimal BFS with cost $-1$.

2.3 Basis formulas, reduced costs, LP KKT

In plain words: for a chosen basis, you can satisfy four of the five KKT conditions automatically. The only one left to check is the sign of the reduced costs $\bar\mu_N$. If they are all $\ge0$, you're optimal. If one is negative, that variable is worth increasing.

Precisely: KKT: $A^T\lambda+\mu=c$, $Ax=b$, $x\ge0$, $\mu\ge0$, $\mu^Tx=0$. The basis construction imposes $x_N=0$ and $\mu_B=0$ (complementarity), and then

$$B x_B=b,\qquad B^T\lambda=c_B,\qquad N^T\lambda+\mu_N=c_N$$ $$\Rightarrow\ \bar x_B=B^{-1}b,\quad \bar\lambda=B^{-T}c_B,\quad \bar\mu_N=c_N-N^T\bar\lambda=c_N-N^TB^{-T}c_B.$$
  • Equalities, stationarity and complementarity now hold. Remaining checks: $\bar x_B\ge0$ (primal feasibility) and $\bar\mu_N\ge0$ (dual feasibility). Both ⇒ optimal (and $c^T\bar x=b^T\bar\lambda$: zero duality gap).
  • Gap identity (why the sign test works): for any feasible $x'$, $c^Tx'-c^T\bar x=(A^T\bar\lambda+\bar\mu)^T(x'-\bar x)=\bar\lambda^T\underbrace{A(x'-\bar x)}_{0}+\bar\mu^Tx'-\underbrace{\bar\mu^T\bar x}_{0}=\bar\mu_N^Tx'_N$. With $\bar\mu_N\ge0$ and $x'\ge0$ this is $\ge0$.
  • At a degenerate basis, $\mu_B=0$ is a choice (complementarity alone would not force it); the construction prescribes it.
Worked example (continuing 2.2)
  1. Basis $\{x_1,x_2\}$: $B=I$, $c_B=(0,0)$ ⇒ $\bar\lambda=0$, $\bar\mu_3=c_3-a_3^T\bar\lambda=-1\lt0$ ⇒ not optimal; $x_3$ should enter.
  2. Basis $\{x_3,x_2\}$: $B^T\lambda=c_B=(-1,0)$ with $B^T=\begin{bmatrix}1&1\\0&1\end{bmatrix}$ ⇒ $\bar\lambda=(-1,0)$. Nonbasic $x_1$: $\bar\mu_1=0-a_1^T\bar\lambda=0-(-1)=1\ge0$ ⇒ optimal (even though degenerate). Check: $c^T\bar x=-1=b^T\bar\lambda=-1$. ✓
Trap $\bar\lambda=B^{-T}c_B$ (transpose!), not $B^{-1}c_B$. $\bar\mu_N=c_N-N^T\bar\lambda$, not $N^T\bar\lambda-c_N$. The gap identity uses $x'_N$ (the other point's nonbasic part), not $\bar x_N$ (which is 0).

2.4 The meaning of one simplex step

In plain words: a negative reduced cost $\bar\mu_q$ says "increasing $x_q$ by one unit lowers the cost by $|\bar\mu_q|$". To keep $Ax=b$, the basic variables must change too, by $-u$ per unit. You increase $x_q$ until the first basic variable hits zero; that one leaves, $x_q$ enters.

Precisely (from a BFS $\bar x$, basis $B$, entering $q$ with $\bar\mu_q\lt0$):

  1. Direction. $u=B^{-1}a_q$ (coordinates of $a_q$ in the basis, $Bu=a_q$). Keep other nonbasics at 0, set $d_q=1$; $Ad=0$ forces $Bd_B+a_q=0$, so $d_B=-u$. Along $x(t)=\bar x+td$: $x_B(t)=\bar x_B-tu$.
  2. Cost slope. $c^Td=c_q-c_B^Tu=c_q-a_q^T\bar\lambda=\bar\mu_q$, so $c^Tx(t)=c^T\bar x+t\bar\mu_q$.
  3. Ratio test. Row $i$ with $u_i\gt0$ decreases and allows $t\le(\bar x_B)_i/u_i$; rows with $u_i\le0$ never block. $\theta=\min_{i:u_i\gt0}(\bar x_B)_i/u_i$. The minimising row $p$ leaves.
  4. Unbounded. If $u\le0$, every $t\ge0$ is feasible; with $\bar\mu_q\lt0$ the cost $\to-\infty$. (With $\bar\mu_q\ge0$ this ray proves nothing.)
  5. Cost change $=\theta\bar\mu_q$: strictly negative iff $\theta\gt0$ and $\bar\mu_q\lt0$.
  6. Degeneracy. If $(\bar x_B)_p=0$ and $u_p\gt0$, then $\theta=0$: basis changes, point and cost do not. So a negative $\bar\mu_q$ at a degenerate BFS does not prove non-optimality (slide p. 81: $\min x_1$, $x_1+x_2=0$: $\bar\mu_2=-1$ but $\theta=0$ and the point is optimal).
  7. Cycling and Bland. Zero steps keep the cost equal, so bases can repeat forever. Bland's rule (smallest-index entering; smallest original index leaving among ties) prevents revisiting a basis ⇒ finite termination. Without degeneracy every step strictly lowers cost, so no basis repeats anyway.
  8. New basis is nonsingular. $B'=B[e_1\cdots u\cdots e_m]$ ($u$ in column $p$), so $\det B'=u_p\det B\ne0$ because the ratio test only picks rows with $u_p\gt0$. True even when $\theta=0$.
Worked example (continuing 2.2, basis $\{x_1,x_2\}$)
  1. $\bar\mu_3=-1$, $u=B^{-1}a_3=(1,1)$. Direction: $d=(-1,-1,1)$, $Ad=0$ ✓, $c^Td=-1=\bar\mu_3$ ✓.
  2. Ratios: $x_1$: $1/1=1$, $x_2$: $1/1=1$ ⇒ $\theta=1$, a tie. Bland: $x_1$ leaves (smaller index).
  3. New point $(1,1,0)+1\cdot(-1,-1,1)=(0,0,1)$; cost change $\theta\bar\mu_3=-1$ ✓. The other tied variable $x_2$ stays basic at $0$ ⇒ the new BFS is degenerate: a tie in the ratio test creates degeneracy.
Trap Ratio test: min (not max), only over $u_i\gt0$ (not $u_i\ne0$, not $u_i\lt0$). $d_B=-u$, not $+u$. "Unbounded" needs both $u\le0$ and $\bar\mu_q\lt0$.

2.5 Tableau: only the first four slides

In plain words: the tableau is the same algebra laid out as a matrix; its last row shows the reduced costs and minus the current cost.

  • From $Bx'_B+Nx'_N=b$: $\;x'_B=\bar x_B-B^{-1}Nx'_N$.
  • Cost: $c^Tx'=c_B^T\bar x_B+(c_N^T-c_B^TB^{-1}N)x'_N=z_0+r_N^Tx'_N$, with $z_0=c_B^TB^{-1}b$, $r_N=\bar\mu_N$.
  • Initial tableau $\begin{bmatrix}B&N&b\\c_B^T&c_N^T&0\end{bmatrix}$ → after row operations $\begin{bmatrix}I&B^{-1}N&B^{-1}b\\0&r_N^T&-z_0\end{bmatrix}$.
  • So: right column = $\bar x_B$; column of $x_q$ in $B^{-1}N$ = $u$; last row = reduced costs, and the bottom-right corner = $-z_0$ (minus the current cost).
Worked example For 2.2 with basis $\{x_1,x_2\}$ ($B=I$ already): rows $[1\ 0\ 1\,|\,1]$, $[0\ 1\ 1\,|\,1]$, last row $[0\ 0\ {-1}\,|\,0]$. Read off: $\bar x_B=(1,1)$, $u$ for $x_3$ $=(1,1)$, $r_3=-1$, $-z_0=0$ so cost $z_0=0$ ✓.

2.6 Equality-constrained QP

In plain words: on the plane $Ax=b$ you can only move in directions $d$ with $Ad=0$. Only the curvature of $f$ along those directions matters. If $f$ curves up along every allowed direction, there is exactly one minimiser, even if $f$ curves down in some forbidden direction.

Precisely ($Q=Q^T$, rank $A=m\lt n$, $Z$ = basis of $\ker A$, $H_r=Z^TQZ$, $g_r=Z^T(Qx_p-c)$, $Ax_p=b$):

  • KKT system: $Qx-c+A^T\lambda=0$, $Ax=b$ ⇔ $K\binom{x}{\lambda}=\binom{c}{b}$. Multiplier unique at a given point ($A^T$ injective). KKT alone does not certify a minimum.
  • Theorem 9.1.1: unique global minimiser $\iff H_r\succ0$. Prop 9.1.2: $H_r\succ0\iff d^TQd\gt0\ \forall\,0\ne d\in\ker A$; $K$ nonsingular $\iff H_r$ nonsingular. Both are independent of the choice of $Z$ ($\tilde Z=ZR$ ⇒ $\tilde H_r=R^TH_rR$).
  • So: $H_r\succ0\Rightarrow K$ nonsingular, but not conversely: $K$ nonsingular with $H_r$ indefinite/negative gives a unique KKT point that is not a minimiser (P3(d)).

Deriving $\phi(z)$ (P1(b); he called it "not difficult and also important"): put $x=x_p+Zz$ in $f$ and expand using $Q=Q^T$:

$$f(x_p+Zz)=\tfrac12x_p^TQx_p+z^TZ^TQx_p+\tfrac12z^TZ^TQZz-c^Tx_p-c^TZz+\gamma$$ $$=f(x_p)+z^T\underbrace{Z^T(Qx_p-c)}_{g_r}+\tfrac12z^T\underbrace{Z^TQZ}_{H_r}z=:\phi(z).$$

Stationarity $\nabla\phi=H_rz+g_r=0$. If $H_r\succ0$: $z^*=-H_r^{-1}g_r$, $x^*=x_p+Zz^*$, and the exact identity $\phi(z)-\phi(z^*)=\tfrac12(z-z^*)^TH_r(z-z^*)\gt0$ for $z\ne z^*$ gives global uniqueness (P2(b)).

Range-space / Schur (P4, $Q$ nonsingular): from stationarity $x=Q^{-1}(c-A^T\lambda)$; put in $Ax=b$: $AQ^{-1}c-AQ^{-1}A^T\lambda=b$ ⇒ $S\lambda=AQ^{-1}c-b$, $S=AQ^{-1}A^T$. $K$ nonsingular $\iff S$ nonsingular. If $Q\succ0$: $\nu^TS\nu=(A^T\nu)^TQ^{-1}(A^T\nu)\gt0$ for $\nu\ne0$ (full row rank gives $A^T\nu\ne0$) ⇒ $S\succ0$. $Q$ nonsingular alone is not enough ($Q=\mathrm{diag}(1,-1)$, $A=[1\ 1]$ ⇒ $S=0$).

Worked example: three methods, one answer $\min\ x_1^2+x_2^2+x_3^2$ s.t. $x_1+x_2+x_3=3$. So $Q=2I$, $c=0$, $A=[1\ 1\ 1]$, $b=3$.
  1. KKT matrix: $2x_i+\lambda=0$ for each $i$, $\sum x_i=3$ ⇒ $x_i=-\lambda/2$, $-3\lambda/2=3$ ⇒ $\lambda=-2$, $x=(1,1,1)$.
  2. Null-space: $x_p=(3,0,0)$, $Z=\begin{bmatrix}-1&-1\\1&0\\0&1\end{bmatrix}$ ($AZ=0$). $H_r=2Z^TZ=\begin{bmatrix}4&2\\2&4\end{bmatrix}\succ0$, $g_r=Z^T(6,0,0)^T=(-6,-6)$. $H_rz=(6,6)$ ⇒ $z^*=(1,1)$, $x^*=(3,0,0)+(-2,1,1)=(1,1,1)$ ✓.
  3. Schur: $S=A(\tfrac12I)A^T=\tfrac32$, $S\lambda=0-3$ ⇒ $\lambda=-2$, $x=\tfrac12(0-A^T\lambda)=(1,1,1)$ ✓.
Trap "Q is indefinite, so no minimum" is wrong: test $Q$ only on $\ker A$. And "K is nonsingular, so the KKT point is the minimiser" is wrong: nonsingular $K$ only gives a unique KKT point.

2.7 Projector, projected gradient, projected CG

In plain words: $P$ removes the part of a vector that would break $Ax=b$. The negative projected gradient is the steepest feasible downhill direction; it is zero exactly at a KKT point.

  • $P=Z(Z^TZ)^{-1}Z^T=I-A^T(AA^T)^{-1}A$: symmetric, $P^2=P$, range $P=\ker A$ (P5(a)–(b)). To apply it without $Z$: solve $(AA^T)u=Av$, then $Pv=v-A^Tu$.
  • $r=P(c-Qx)=-P\nabla f(x)$: $x+\alpha r$ stays feasible for all $\alpha$, and $\nabla f^Tr=-\nabla f^TP^TP\nabla f=-\|r\|^2\lt0$ if $r\ne0$ ⇒ descent direction, FONC fails.
  • $r=0\iff$ KKT stationarity $\iff$ FONC; with $H_r\succ0$ it certifies the unique minimiser.
  • Projected CG (relation only): with $Z^TZ=I$ it is ordinary CG on $H_rz=Z^T(c-Qx_p)$, so it ends in at most $n-m$ steps (CG on an $(n-m)$-dimensional problem).
Worked example $A=[1\ 1]$, $\nabla f(x)=(3,1)$. $AA^T=2$, $P=I-\tfrac12\begin{bmatrix}1&1\\1&1\end{bmatrix}=\begin{bmatrix}\tfrac12&-\tfrac12\\-\tfrac12&\tfrac12\end{bmatrix}$. $r=-P\nabla f=(-1,1)$: $Ar=0$ ✓, $\nabla f^Tr=-3+1=-2=-\|r\|^2$ ✓.

2.8 Inequality QP: one active-set step

In plain words: pretend the constraints in your working set are equalities and find the best shift $p$. If the shift is nonzero, walk towards $x_k+p_k$, but stop early if some other constraint gets in the way. If the shift is zero, you are optimal for the equality version; now check the multipliers' signs. A negative one means that constraint is "holding you back the wrong way", so let it go.

Precisely (problem $\min\tfrac12x^TQx-c^Tx$ s.t. $a_i^Tx\le b_i$; $W_k\subseteq\mathcal A(x_k)$ with independent normals; $g_k=Qx_k-c$):

  1. Subproblem written via the gradient (he stressed this form): $f(x_k+p)=f(x_k)+g_k^Tp+\tfrac12p^TQp$, so minimising $f(x_k+p)$ is minimising $q_k(p)=g_k^Tp+\tfrac12p^TQp$ over $S(W_k)=\{p:a_i^Tp=0,\ i\in W_k\}$. ($p_k$ solves this $\iff x_k+p_k$ solves the equality problem $P_k$.)
  2. Descent: if $p_k\ne0$ (and $Q$ PD on $S(W_k)$): since $\alpha p_k\in S(W_k)$, $\frac{d}{d\alpha}q_k(\alpha p_k)|_{\alpha=1}=g_k^Tp_k+p_k^TQp_k=0$ ⇒ $g_k^Tp_k=-p_k^TQp_k\lt0$. Then $f(x_k+\alpha p_k)-f(x_k)=\alpha g_k^Tp_k+\tfrac{\alpha^2}2p_k^TQp_k=-\alpha(1-\tfrac\alpha2)p_k^TQp_k$: every $0\lt\alpha\lt2$ decreases $f$; $\alpha=1$ is the best.
  3. Feasibility: working constraints stay equalities ($a_i^Tp_k=0$). Constraint $i\notin W_k$ is only threatened if $a_i^Tp_k\gt0$; it allows $\alpha\le(b_i-a_i^Tx_k)/a_i^Tp_k$. Hence $\alpha_k=\min_{i\notin W_k,\,a_i^Tp_k\gt0}\frac{b_i-a_i^Tx_k}{a_i^Tp_k}$ ($+\infty$ if none).
  4. Step $\min\{1,\alpha_k\}$: $\alpha_k\gt1$: nothing blocks, full step $x_{k+1}=x_k+p_k$, $W$ unchanged. $\alpha_k\le1$: step $\alpha_k$, add one blocker $l_k$ to $W$ (even if several tie). $\alpha_k=0$: an omitted active constraint blocks, $x$ stays, $W$ grows.
  5. $p_k=0$: $x_k$ is the unique minimiser on the working set; solve $g_k+\sum_{i\in W_k}\lambda_ia_i=0$. All $\lambda_i\ge0$ ⇒ (with $Q\succeq0$) $x_k$ is a global minimiser (Thm 9.2.4; extend $\lambda$ by 0 off $W_k$ to get full KKT). Some $\lambda_j\lt0$ ⇒ drop $j$ (most negative); the new direction has $a_j^Tp\lt0$ (moves strictly inside constraint $j$) and $g^Tp\lt0$ (P10).
Worked example (both step cases) $\min\tfrac12\|x-(2,2)\|^2$, i.e. $Q=I$, $c=(2,2)$; constraints (1) $x_1\le1$, (2) $x_2\le3$. Start $x_0=(0,0)$, $W_0=\varnothing$ (nothing active).
  1. $g_0=x_0-c=(-2,-2)$. No constraints in $W_0$ ⇒ $p_0=-g_0=(2,2)$. Check $g_0^Tp_0=-8=-p_0^Tp_0$ ✓.
  2. Ratios: (1) $a_1^Tp_0=2\gt0$, slack $1$ ⇒ $0.5$; (2) $a_2^Tp_0=2$, slack $3$ ⇒ $1.5$. $\alpha_0=0.5\lt1$ ⇒ step $0.5$: $x_1=(1,1)$, add (1): $W_1=\{1\}$.
  3. $g_1=(-1,-1)$; $a_1^Tp=0$ ⇒ $p=(0,p_2)$, minimise $-p_2+\tfrac12p_2^2$ ⇒ $p_1=(0,1)$.
  4. Ratio: (2) $a_2^Tp_1=1$, slack $3-1=2$ ⇒ $\alpha_1=2\gt1$ ⇒ full step (not 2!): $x_2=(1,2)$, $W_2=\{1\}$.
  5. Now $p_2=0$. $g_2=(-1,0)$; $g_2+\lambda_1(1,0)=0$ ⇒ $\lambda_1=1\ge0$ ⇒ optimal: $x^*=(1,2)$ (the projection of $(2,2)$ onto $x_1\le1$ ✓).
Trap If $\alpha_k\gt1$ you take step 1, not $\alpha_k$: $\alpha_k$ only says the constraints don't block; going further moves away from the subproblem minimiser. Ratio test is over $i\notin W_k$ with $a_i^Tp_k\gt0$ only. A zero direction is not "done" until the multiplier signs are checked.
