1. Must remember

Memorise cold
  • Primal (always rewrite into this form first): $\min_x f(x)$ s.t. $h(x)=0$, $g(x)\le 0$. Lagrangian $L(x,\lambda,\mu)=f(x)+\lambda^Th(x)+\mu^Tg(x)$, $\lambda$ free, $\mu\ge 0$. (The notes write the multipliers as $y=(u,v)$; same thing.)
  • Dual function $q(\lambda,\mu)=\inf_{x\in\mathbb{R}^n}L(x,\lambda,\mu)$: infimum over all $x$, constraints are not put back. Domain $\mathbb{D}=\{(\lambda,\mu):q\gt-\infty\}$. Dual problem: $\max q(\lambda,\mu)$ s.t. $(\lambda,\mu)\in\mathbb{D}$, $\mu\ge0$.
  • Linear-in-$x$ rule: $\inf_x (r^Tx+\beta)=\beta$ if $r=0$, and $-\infty$ otherwise. ("The infimum is finite if and only if the coefficient of $x$ vanishes.")
  • $q$ is concave and $\mathbb{D}$ is convex, even when the primal is nonconvex (because $L$ is affine in the multipliers).
  • Weak duality: $x$ feasible, $\mu\ge0$ ⇒ $q(\lambda,\mu)\le L(x,\lambda,\mu)\le f(x)$. Hence $d^*\le p^*$.
  • Standard LP pair: $\ \min c^Tx$ s.t. $Ax=b,\ x\ge0\quad\Longleftrightarrow\quad \max b^T\lambda$ s.t. $A^T\lambda\le c$ ($\lambda$ free).
  • LP KKT: $A^T\lambda^*+\mu^*=c,\ \ \mu^*\ge0,\ \ Ax^*=b,\ \ x^*\ge0,\ \ (\mu^*)^Tx^*=0$. Value identity $c^Tx^*=b^T\lambda^*$.
  • LP duality theorem: (i) one has an optimal solution ⇒ both do, equal values. (ii) one unbounded ⇒ the other infeasible. The converse of (ii) is FALSE: both can be infeasible.
  • KKT-equivalence (Thm 7.4.1), differentiable convex, full space: a KKT pair exists ⇔ $p^*=d^*\in\mathbb{R}$ and both are attained. Then every primal optimum with every dual optimum is a KKT pair.
  • Slater (Thm 7.4.3): $f,g$ convex, $h$ affine, some $x^0$ with $h(x^0)=0$, $g(x^0)\lt 0$, and $p^*$ finite ⇒ $p^*=d^*$ and the dual optimum is attained. Primal attainment is NOT guaranteed.
  • Primal recovery (Cor 7.4.2): KKT pair exists, $\bar y$ dual optimal, $L(\cdot,\bar y)$ has a unique minimiser $\bar x$ ⇒ $\bar x$ is the unique primal optimum (feasibility and complementary slackness come free). Uniqueness, not strict convexity, is the hypothesis.
  • Convex feasible set from: $h(x)=0$ with $h$ affine; $g(x)\le0$ with $g$ convex; $g(x)\ge0$ with $g$ concave.
  • Never write "concave optimization problem" or "concave set".

2. Concepts

2.1 What makes a problem convex, and what convexity buys you

In plain words: a convex problem is "minimise a bowl-shaped function over a set with no dents". Then any local minimum is the global one, and the KKT equations are enough to prove a point is the global minimum.

Precisely: the problem $\min f(x)$ s.t. $h(x)=0,\ g(x)\le0$ is a convex optimization problem if $f$ and every $g_j$ are convex and $h$ is affine. For such problems:

  • Feasible set is convex (Thm 7.2.1: affine $=$, convex $\le$, concave $\ge$; intersections stay convex).
  • Local minimum ⇒ global minimum (Thm 7.2.3). The set of minimisers is convex (Cor 7.2.6).
  • Geometric FONC (Thm 7.2.4): $x^*$ is a global minimiser iff $\nabla f(x^*)^T(y-x^*)\ge0$ for every feasible $y$. So $\nabla f(x^*)$ need not be $0$ at a constrained optimum.
  • KKT ⇒ global minimum (Thm 7.2.8), with no constraint qualification needed. But KKT is not necessary without a CQ (e.g. Slater).
Worked example: which constraints keep the feasible set convex?
  1. $x_1^2+x_2^2-4\le0$: convex function $\le 0$ ✓.
  2. $-x_1\le0$ (i.e. $x_1\ge0$): affine is convex ✓.
  3. $\ln x_1\ge 0$ (on $x_1\gt0$): concave function $\ge0$ ✓.
  4. $x_1^2+x_2^2=1$: equality with a non-affine function ✗ (circle, not convex).
  5. $x_1^2-x_2\ge0$: convex function $\ge0$ ✗ (outside of a parabola, not convex).
Worked example: KKT holds nowhere, yet the optimum exists

$\min (x-1)^2$ s.t. $x^2\le0$. Only feasible point $x^*=0$, so it is the global minimiser. Stationarity would need $2(0-1)+2\mu\cdot0=0$, i.e. $-2=0$: no multiplier. Strict convexity does not replace a constraint qualification. (Slater fails: no $x$ with $x^2\lt0$.)

Trap: convexity along a line $f=x_1^2-x_2^2$ is not convex on $\mathbb{R}^2$, but restricted to the line $\{(t,at)\}$ it is $(1-a^2)t^2$, convex iff $|a|\le1$. Only the curvature along the set matters ($F^T\nabla^2 f\,F\succeq0$), not the full Hessian. And at $a=\pm1$ the restriction is constant, which still counts as convex.

2.2 The proof chain: KKT ⇒ global minimum (Midterm 2 Q I)

In plain words: take any feasible $y$, look at the step $d=y-x^*$, and show $f$ cannot go down along it.

The five steps (learn the reason for each)
  1. Equality: $Ad=Ay-Ax^*=b-b=0$, so $d^TJ_h(x^*)=(Ad)^T=0^T$ (here $J_h=A^T$).
  2. Convex $g_j$: $\nabla g_j(x^*)^Td\le g_j(y)-g_j(x^*)$. Active $j$ ($g_j(x^*)=0$): $\le g_j(y)\le0$. Inactive: no fixed sign.
  3. Complementary slackness kills inactive $\mu_j$; active ones are $\ge0$ times $\le0$: so $d^TJ_g(x^*)\mu^*\le0$.
  4. Convex $f$ + stationarity of the Lagrangian: $f(y)-f(x^*)\ge\nabla f(x^*)^Td=-d^T[J_h\lambda^*+J_g\mu^*]$.
  5. Combine: $f(y)-f(x^*)\ge -d^TJ_g\mu^*\ge0$. Global minimum. Contrapositive: a point that is not a (local) minimiser cannot satisfy KKT.

2.3 Lagrangian, dual function, and its domain $\mathbb{D}$

In plain words: for each fixed price vector $(\lambda,\mu)$ you minimise the "penalised" cost $L$ over every $x$, ignoring the constraints. The answer $q(\lambda,\mu)$ is a lower bound on the true optimum. Where the minimisation runs off to $-\infty$, that price vector is useless (outside $\mathbb{D}$).

Precisely: $q(\lambda,\mu)=\inf_{x\in\mathbb{R}^n}L(x,\lambda,\mu)$; $\mathbb{D}=\{q\gt-\infty\}$. If the problem has an explicit function domain (e.g. $y\gt0$ because of $x^2/y$), that domain stays in the infimum; only constraints you put into $L$ are dropped.

How to compute the infimum:

  • $L$ linear in some variable: coefficient must be $0$, else $q=-\infty$.
  • $L$ a positive definite quadratic in $x$: set $\nabla_xL=0$, solve for $x(\lambda,\mu)$, substitute back (or complete the square).
  • Quadratic with coefficient that can be $\le 0$, or exponential terms: check the edge cases separately (e.g. $e^x+\mu x$: $\mu\gt0$ gives $-\infty$ as $x\to-\infty$).
Worked example (notes Example 7.4.2)

$\min x$ s.t. $-x\le0$. $L=x-\mu x=(1-\mu)x$. Linear in $x$: finite only if $1-\mu=0$.

$q(\mu)=0$ if $\mu=1$, $-\infty$ otherwise. $\mathbb{D}=\{1\}$, $d^*=0=p^*$ (at $x^*=0$).

But $L(x,1)\equiv0$: every $x$ minimises it, including $x=-1$ (infeasible) and $x=1$ (feasible, not optimal). So minimising $L$ at $\mu^*$ does not by itself give $x^*$ when the minimiser is not unique.

2.4 Weak duality, and why $q$ is always concave

In plain words: every dual value is below every feasible primal value. So any feasible pair with equal values proves both are optimal.

Proof (he wants this remembered): for feasible $\bar x$ and $\bar\mu\ge0$: $$q(\bar\lambda,\bar\mu)\le L(\bar x,\bar\lambda,\bar\mu)=f(\bar x)+\bar\lambda^T\underbrace{h(\bar x)}_{=0}+\underbrace{\bar\mu^Tg(\bar x)}_{\le0}\le f(\bar x).$$

Concavity of $q$: for fixed $x$, $L$ is affine in $(\lambda,\mu)$. An infimum of affine functions is concave: $q(\alpha y_0+(1-\alpha)y_1)=\inf_x[\alpha L(x,y_0)+(1-\alpha)L(x,y_1)]\ge\alpha q(y_0)+(1-\alpha)q(y_1)$. Then $\mathbb{D}$ is convex because the right side is $\gt-\infty$ when both endpoints are in $\mathbb{D}$. No convexity of $f,g$ used. So the dual is always a convex optimization problem (maximise concave = minimise convex $-q$).

Worked example A feasible $\hat x$ has $f(\hat x)=7$, a dual-feasible $\hat\eta$ has $q(\hat\eta)=4$. Then $4\le d^*\le p^*\le7$. Nothing more: no zero gap, no optimality of either point.

2.5 THE RECIPE: deriving a dual (and the QP example from the tutorial)

Recipe (write every step in the exam)
  1. Rewrite constraints as $h(x)=0$, $g(x)\le0$ (e.g. $x_1\ge2\to 2-x_1\le0$; $x\ge0\to -x\le0$). Name multipliers: $\lambda$ free for $h$, $\mu\ge0$ for $g$.
  2. Write $L=f+\lambda^Th+\mu^Tg$ and collect terms in $x$.
  3. Take $\inf$ over all $x\in\mathbb{R}^n$ (no constraints put back). Linear parts: coefficient $=0$. Quadratic parts: $\nabla_xL=0$.
  4. Write $q$ with its domain $\mathbb{D}$ (where it is $\gt-\infty$).
  5. Eliminate "slack" multipliers (those that appear only in the coefficient conditions, e.g. $\mu$ for $x\ge0$): $\mu=\ldots\ge0$ becomes an inequality on the rest.
  6. Dual: maximise $q$ over the remaining multipliers with their sign restrictions.
  7. (QP) Maximise; check $\mu^*\ge0$ (if the unconstrained maximiser has $\mu\lt0$, maximise on the boundary $\mu=0$). Recover $\bar x=\arg\min_xL(x,\lambda^*,\mu^*)$; if unique it is $x^*$. Check $p^*=d^*$. Name a Slater point.
Worked example: Ch 7 tutorial problem V (Problem set part 2, V)

$\displaystyle\min_{x\in\mathbb{R}^2}\tfrac12(2x_1^2+x_2^2)$ s.t. $h(x)=x_1+x_2-4=0$, $g(x)=2-x_1\le0$.

  1. Slater point: $x^0=(3,1)$: $h=0$, $g=-1\lt0$ ✓. $f$ strictly convex ⇒ any KKT point is the unique global minimiser.
  2. $L=x_1^2+\tfrac12x_2^2+\lambda(x_1+x_2-4)+\mu(2-x_1)$, $\lambda\in\mathbb{R}$, $\mu\ge0$.
  3. $L$ is a PD quadratic in $x$ for every $(\lambda,\mu)$, so $\nabla_xL=0$: $2x_1+\lambda-\mu=0$, $x_2+\lambda=0$ ⇒ $x_1=\frac{\mu-\lambda}{2}$, $x_2=-\lambda$. Here $\mathbb{D}=\mathbb{R}^2$.
  4. Substitute: $q(\lambda,\mu)=-\tfrac14(\lambda-\mu)^2-\tfrac12\lambda^2-4\lambda+2\mu$.
  5. Complete the square: $q(\lambda,\mu)=6-\tfrac14(\lambda-\mu+4)^2-\tfrac12(\lambda+2)^2$. Max when both squares are $0$: $\lambda^*=-2$, $\mu^*=2\ge0$ ✓, $d^*=6$.
  6. Recover: $L(x,-2,2)=(x_1-2)^2+\tfrac12(x_2-2)^2+6$, unique minimiser $\bar x=(2,2)$ ⇒ $x^*=(2,2)$ by the recovery corollary.
  7. Check: $x_1+x_2=4$ ✓, $x_1=2\ge2$ (active) ✓, $p^*=\tfrac12(8+4)=6=d^*$ ✓. Stationarity: $(2x_1,x_2)+\lambda(1,1)+\mu(-1,0)=(4-2-2,\,2-2)=(0,0)$ ✓. CS: $\mu(2-x_1)=2\cdot0=0$ ✓.
Trap: two errors in older summaries The end-term guide's one-liner says "$2x_1^2+x_2^2$ … $x^*=(1,2)$". Wrong: $(1,2)$ is not even feasible ($1+2=3\ne4$, and $1\lt2$). The objective has a $\tfrac12$ and the answer is $x^*=(2,2)$, $\lambda^*=-2$, $\mu^*=2$, $p^*=d^*=6$ (checked with sympy). The handwritten tutorial solution's completed square shows $\tfrac12(\lambda-\mu+4)^2$; the correct coefficient is $\tfrac14$ (same maximiser, same value).

2.7 LP duality: the standard-form derivation and LP KKT

In plain words: for an LP the Lagrangian is linear in $x$, so the dual function is finite only when the coefficient of $x$ is zero. That one condition becomes the dual constraints.

Precisely (his derivation, Ch 7 §7.6): $\min c^Tx$ s.t. $Ax=b$, $x\ge0$. Use $h(x)=b-Ax$ (multiplier $\lambda$ free), $g(x)=-x$ (multiplier $\mu\ge0$): $$L=c^Tx+\lambda^T(b-Ax)-\mu^Tx=(c-A^T\lambda-\mu)^Tx+b^T\lambda.$$ $$q(\lambda,\mu)=\begin{cases}b^T\lambda,& A^T\lambda+\mu=c\\-\infty,&\text{otherwise}\end{cases}\quad\Rightarrow\quad \max_\lambda b^T\lambda\ \text{ s.t. } \mu=c-A^T\lambda\ge0\iff A^T\lambda\le c.$$ LP weak duality in one line: $c^Tx-b^T\lambda=(c-A^T\lambda)^Tx=\mu^Tx\ge0$. LP KKT (no LICQ needed, because the tangent cone of linear constraints is exact): $A^T\lambda^*+\mu^*=c$, $\mu^*\ge0$, $Ax^*=b$, $x^*\ge0$, $(\mu^*)^Tx^*=0$, and then $c^Tx^*=(A^T\lambda^*+\mu^*)^Tx^*=b^T\lambda^*$.

Worked example: Ch 7 tutorial problem II (Problem set part 2, II)

$\min 2x_1+3x_2+6x_3$ s.t. $x_1+x_2+x_3=5$, $2x_1+x_2=6$, $x\ge0$.

  1. $A=\begin{pmatrix}1&1&1\\2&1&0\end{pmatrix}$, $b=(5,6)$, $c=(2,3,6)$. Dual: $\max 5\lambda_1+6\lambda_2$ s.t. $\lambda_1+2\lambda_2\le2$, $\lambda_1+\lambda_2\le3$, $\lambda_1\le6$; $\lambda$ free.
  2. Try $\lambda=(4,-1)$: $\mu=c-A^T\lambda=(2-2,\ 3-3,\ 6-4)=(0,0,2)\ge0$ ✓ dual feasible; dual value $20-6=14$.
  3. CS: $\mu_3=2\gt0$ ⇒ $x_3=0$. Then $x_1+x_2=5$, $2x_1+x_2=6$ ⇒ $x=(1,4,0)\ge0$ ✓. Primal value $2+12=14$.
  4. Equal values ⇒ both optimal (weak duality). $p^*=d^*=14$ (checked with linprog). Since $x_1,x_2\gt0$, CS forces the first two dual constraints tight ⇒ $\lambda=(4,-1)$ is the unique dual optimum.

2.8 Non-standard LP forms (what he will give you)

Use the same recipe; only the bookkeeping changes. The three patterns:

  • Free variable $x_j$ (no sign constraint, no multiplier): its coefficient in $L$ must be exactly $0$ ⇒ an equality in the dual.
  • Sign-constrained variable $x_j\ge0$: gives a multiplier $s_j\ge0$ in the coefficient; eliminating it gives an inequality in the dual.
  • Inequality row ($\ge$ or $\le$): rewrite as $(\cdot)\le0$; its multiplier is $\ge0$. Equality row: multiplier free.
Worked example: inequality form, $x$ free

$\min c^Tx$ s.t. $Ax\le b$. $g=Ax-b\le0$, $\mu\ge0$. $L=c^Tx+\mu^T(Ax-b)=(c+A^T\mu)^Tx-b^T\mu$. $x$ free ⇒ need $c+A^T\mu=0$. Dual: $\max_\mu -b^T\mu$ s.t. $A^T\mu=-c$, $\mu\ge0$.

Worked example: the self-dual LP (Midterm 2 Q II, summary)

$\min q^Tz$ s.t. $Mz\ge-q$, $z\ge0$, with $M^T=-M$. Multipliers $\lambda\ge0$ for $-Mz-q\le0$, $\mu\ge0$ for $-z\le0$. Using $-\lambda^TMz=-(M^T\lambda)^Tz=(M\lambda)^Tz$: $L=(q+M\lambda-\mu)^Tz-q^T\lambda$. Finite iff $\mu=q+M\lambda$; $\mu\ge0\iff M\lambda\ge-q$. Dual: $\max -q^T\lambda$ s.t. $M\lambda\ge-q$, $\lambda\ge0$: same feasible set, so $d^*=-p^*$. Since $z^TMz=0$, every feasible $z$ has $q^Tz=z^T(Mz+q)\ge0$. Feasible ⇒ bounded ⇒ optimal; strong duality ⇒ $p^*=d^*=-p^*$ ⇒ both $0$.

Traps in LP duals
  • Primal is a max? Convert to $\min(-c^Tx)$ first, derive, then flip back. $\max c^Tx$, $Ax\le b$, $x\ge0$ has dual $\min b^Ty$, $A^Ty\ge c$, $y\ge0$.
  • Equality multiplier sign depends on whether you wrote $b-Ax$ or $Ax-b$; both are right if you are consistent (they differ by $\lambda\to-\lambda$). He says: don't change the convention mid-problem.
  • Infeasible ⇏ unbounded. Example: $A=[0]$, $b=1$, $c=-1$: primal $0\cdot x=1$ and dual $0\cdot\lambda\le-1$ are both infeasible.

Q1 Quiz 4 Q1 (past paper)MCQ

Let $f(x_1,x_2)=x_1^2-x_2^2$ and $\Omega_a=\{(t,at):t\in\mathbb{R}\}$. For exactly which $a$ is the restriction of $f$ to $\Omega_a$ convex?

  1. (a) $|a|\le1$.
  2. (b) $|a|\lt1$.
  3. (c) $|a|\ge1$.
  4. (d) For no $a$, because the full Hessian of $f$ is indefinite.
Show answer

Answer: (a). $\phi_a(t)=f(t,at)=(1-a^2)t^2$, $\phi_a''=2(1-a^2)\ge0\iff|a|\le1$.

(b) drops $a=\pm1$, where $\phi$ is constant: constant functions are convex (just not strictly). (c) is where the restriction is concave. (d) The ambient Hessian is irrelevant; only curvature along the line counts.

Q2 Quiz 4 Q2 (past paper)MCQ

$q(\eta)=\inf_{x\in D}L(x,\eta)$ where $L$ is affine in $\eta$ for each fixed $x$; $\mathcal{D}=\{\eta:q(\eta)\gt-\infty\}$ nonempty, $q$ never $+\infty$. Which must hold?

  1. (a) $q$ is convex and $\mathcal{D}$ is convex.
  2. (b) $q$ is concave only when the primal objective is strictly convex.
  3. (c) $q$ is concave, but $\mathcal{D}$ need not be convex.
  4. (d) $q$ is concave and $\mathcal{D}$ is convex, even when the primal problem is nonconvex.
Show answer

Answer: (d). Infimum of affine functions is concave; finiteness at two endpoints plus concavity keeps the combination finite, so $\mathcal{D}$ is convex. No convexity of $f,g$ is used.

(a) $q$ is concave, not convex. (b) concavity needs nothing from the primal. (c) $\mathcal{D}$ is always convex.

Q3 Quiz 4 Q3 (past paper)MCQ

A primal-feasible $\hat x$ and a dual-feasible $\hat\eta$ satisfy $f(\hat x)=7$, $q(\hat\eta)=4$. Neither is known to be optimal. Which must hold?

  1. (a) $4\le p^*\le d^*\le7$.
  2. (b) $4\le d^*\le p^*\le7$.
  3. (c) $p^*\le4\le7\le d^*$.
  4. (d) $p^*=7$ and $d^*=4$.
Show answer

Answer: (b). $4=q(\hat\eta)\le d^*$ (sup), $d^*\le p^*$ (weak duality), $p^*\le f(\hat x)=7$ (inf).

(a) puts $p^*\le d^*$: wrong direction of weak duality. (c) reverses both bounds. (d) treats feasible values as optimal.

Answer: (b). $f(y)-f(x^*)\ge\nabla f(x^*)^Td$ (convexity) and $\nabla f(x^*)=-(J_h\lambda^*+J_g\mu^*)$ (stationarity).

Write the full LP KKT system and the value identity.

Show answer

$A^T\lambda^*+\mu^*=c$, $\mu^*\ge0$, $Ax^*=b$, $x^*\ge0$, $(\mu^*)^Tx^*=0$. Then $c^Tx^*=(A^T\lambda^*+\mu^*)^Tx^*=b^T\lambda^*$.

S3

Define $q$ and $\mathbb{D}$. Over which set is the infimum taken? What two properties do they always have, and why?

Show answer

$q(\lambda,\mu)=\inf_{x\in\mathbb{R}^n}L(x,\lambda,\mu)$, over the whole space (or the function domain), not the feasible set. $\mathbb{D}=\{q\gt-\infty\}$. $q$ concave, $\mathbb{D}$ convex, because $L$ is affine in the multipliers; no convexity of the primal needed.

S4

State weak duality and prove it in one line.

Show answer

$x$ feasible, $\mu\ge0$: $q(\lambda,\mu)\le L(x,\lambda,\mu)=f(x)+\lambda^Th(x)+\mu^Tg(x)\le f(x)$ since $h(x)=0$ and $\mu^Tg(x)\le0$. So $d^*\le p^*$.

S5

State Slater's theorem (hypotheses and conclusion) and name one thing it does NOT give, with an example.

Show answer

$f,g_j$ convex, $h$ affine, $\exists x^0$: $h(x^0)=0$, $g_j(x^0)\lt0\ \forall j$; if $p^*$ finite then $p^*=d^*$ and a dual optimum exists. Not primal attainment: $\min e^x$, $x\le0$. Also not a unique Lagrangian minimiser: $-2u+(v-1)^2$, $u\le1$.

S6

State the KKT-equivalence theorem (7.4.1) and the primal-recovery corollary (7.4.2).

Show answer

Differentiable convex $f,g$, affine $h$, full space: a KKT pair exists ⇔ $p^*=d^*\in\mathbb{R}$ and both are attained; then every primal optimum with every dual optimum is a KKT pair. Recovery: under this, if $\bar y$ is dual optimal and $L(\cdot,\bar y)$ has a unique minimiser $\bar x$, then $\bar x$ is the unique primal optimum (feasible, CS holds automatically).

S7

State the LP duality theorem (both parts) and the false converse, with a counter-example.

Show answer

(i) If (P) or (D) has an optimal solution, so does the other and the values are equal. (ii) If one is unbounded, the other is infeasible. False: "infeasible ⇒ other unbounded". $A=[0]$, $b=1$, $c=-1$: both infeasible.

S8

Which three constraint types give a convex feasible set? Is KKT necessary for a convex problem? Sufficient? Give the counter-example for one of them.

$h=0$ with $h$ affine; $g\le0$ with $g$ convex; $g\ge0$ with $g$ concave.
